# 货币换算器

Aether 插件项目 v1，Node ESM，版本 1.0.1。支持 34 种币种的单笔换算、批量换算、交叉汇率表和币种查询。

## 使用方式

发布并启用后，可在 Aether 的插件原生操作页直接选择功能、输入字段、运行并查看结果，不必创建聊天会话。操作页由 aether-plugin.json 中的 inputSchema 自动生成。
如需在聊天中使用，由用户在会话中 @ 选择此插件；创建或发布插件不会自动增加当前会话的工具权限。

功能：convert（单笔换算）、batch_convert（批量换算）、cross_table（汇率表）、list_currencies（查询币种）。

## 汇率来源与方向

内置汇率是原始插件保留的演示数值，没有可验证的数据来源或日期，不能当作当前行情。本插件不访问网络，也不自动获取实时汇率。
实际换算请提供经你核实的 rate 或本次涉及币种的完整 rates。
- rate：仅用于单笔换算，表示 1 单位源币种可兑换的目标币种数量；优先于 rates。同币种换算只能为 1。
- rates：每个值表示 1 USD 可兑换的该币种数量；如填写 USD，其值必须为 1。未覆盖的币种保留内置演示值。
- rateSource 为 direct / custom：本次所用汇率均由参数提供；builtin：使用内置演示值；mixed：同时涉及参数汇率和演示值。无关币种覆盖不会被误报为本次自定义汇率。
- 数值与字符串中的汇率用于结果展示；正的小汇率使用科学计数法保留，不会被显示成 0。金额计算直接使用原始十进制金额和汇率表值进行精确乘除。

直接指定的 rate 数值与文本保留输入精度。表达式只在所显示金额与汇率的精确乘积等于显示结果时使用等号；存在汇率展示近似或金额舍入时使用 ≈。

## 数字范围与舍入

金额必须为有限非负数字且不超过 1e15。指定汇率和自定义汇率值必须在 1e-12 到 1e12 范围内。
按目标币种小数位使用十进制 half-up（四舍五入），例如 1.005 × 3 = 3.015，保留两位后为 3.02。日元、韩元等按清单配置取整。
为保证数值结果与展示结果一致，目标币种的最小单位数量不能超过 JavaScript 安全整数，且结果必须可由返回的数字安全表示。超出时明确拒绝，需减小金额或汇率。
输入协议使用 JSON number，按接收到的数字的十进制表示计算；不支持超出 JSON number 表达精度的任意位金额。

## 标准项目与独立运行

项目文件：aether-plugin.json、main.mjs、package.json、README.md、examples/cases.json、scripts/test.mjs。
需要 Node.js 22 或更新版本，无第三方运行依赖。运行 npm test 可检查具有固定预期结果的业务示例。宿主另行校验输入 Schema、发布版本、权限和执行限制。
独立协议：向 main.mjs 的标准输入写入一行 {"tool":"convert","args":{"amount":100,"from":"USD","to":"CNY","rate":7.28}} 并关闭输入，成功时标准输出返回一行 {"result":...}。错误写入标准错误并使用非零退出码。
外部平台可按此协议包装为自己的工具或适配器；本项目不会自动注册到第三方平台，也不包含第三方平台专属清单。

插件不产生文件成果，不读写用户文件，不调用网络；操作页结果是运行预览。
