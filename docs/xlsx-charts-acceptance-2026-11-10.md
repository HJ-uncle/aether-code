# Excel 原生图表与 Work 预览验收

日期：2026-11-10。接续办公文件内容审查，为 Excel 增加图表生成、数据关联及 Work 内预览。使用隔离夹具和当前构建，没有运行旧 E2E、导出界面测试，没有调用生产模型或修改用户办公文件。

## 已实现

- 通过现有 `office_document` 创建或追加工作表时，可声明柱形、条形、折线、面积、饼、环形、散点七种原生图表。
- 图表引用工作表列与实际单元格范围，不要求模型重复传一份图表数据；保留 Excel 原生图表对象。现有技能参考同步参数和限制，没有增加第二套固定模板。
- 修改单元格或公式重算时，刷新支持的本地单行/单列引用缓存。缺失值和待计算公式保持空缺，不伪填零；命名、外部或复杂引用保持原缓存并告警。
- Work 按文件原有锚点显示图表；底部“图表”菜单可直接定位全部图表，在同一预览中适应宽度查看，支持图形/数据切换、图例和悬停数值。
- 返回工作表恢复滚动位置。菜单支持键盘操作，窄窗口下控件可达。预览读取当前单元格值，避免旧图表缓存误导。
- 预览支持单元格定位、稀疏缓存、日期基准、系列及数据点颜色。解析有数量、大小和 XML 边界，不读取外部链接。

## 验收中修复的问题

- 数值缩放曾产生 7.6 等刻度却四舍五入显示为 8；改用安全的十进制尺度，常见 8–38 数据现在显示 0/10/20/30/40，同时保留极端数值和微小差异处理。
- 散点与折线边缘数据点被裁切；扩大绘图裁切边界。
- 四个短月份标签被过度省略；改按实际估算宽度控制标签密度。
- 深色模式下图表周围仍有白底和浅灰块；文档画布保留纸张颜色，导航及外围区域完整跟随应用主题。
- 浅色模式的返回按钮文字对比度不足；采用主要文字令牌，明暗主题均通过 4.5:1 检查。

测试编写期间还修正了三个夹具/断言问题：自定义选择器使用 menuitem 语义；SVG title 是提示文字，不能混入实际标签文本断言；原尺寸图表比窄面板宽时，应先滚动到右侧查看按钮。最终断言仍验证真实数据与可操作结果。

## 能力边界

- Work 图表是只读预览；原生图表可由 Excel 继续编辑。此次没有加入在 Work 中拖拽编辑图表结构或任意修改图表类型的界面/API。
- 创建每表最多 8 图、每图最多 8 系列及 1000 个数据点；饼/环仅单系列非负数据。已有复杂图表受预览边界限制。
- 堆积、3D、组合、对数或反向轴等复杂设置显示不支持说明并保留原文件；固定轴上下界、趋势线、误差线等不完全支持的设置会提示预览差异，不能把预览称为原生 Office 完全还原。
- 未扩展原有公式计算范围，未验证图表打印/PDF 导出，也未进行生产模型对话或长时间压力测试。
- 当前开发实例使用固定引擎快照，需重新启动 `npm run dev` 才会加载新引擎。本次测试使用全新构建，不代表已经替换正在运行的开发实例。
