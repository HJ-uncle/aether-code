# 完全访问与确认记录排查（2026-10-10）

截图中的“已完成 / 确认记录 / 已允许这次操作”属于已经处理的历史授权，不能据此认定当前命令仍在等待审批。旧界面直接回显原始问句“是否允许执行？”，容易让人误解。

## 本次修改

- 客户端 `ChatView.tsx`：已处理的权限记录标注“当时请求确认（已处理）”，将引擎固定审批问句改为历史原因说明。保留授权结果与原因，不改写引擎历史数据。
- 引擎 `src/tools/cmd/execute-command.ts`：命令预检与执行模式从 `rootSessionId ?? sessionId` 读取。子代理创建时原本会复制父会话模式，但运行中父会话切换后，子会话快照不会更新；现在命令检查跟随根会话当前设置。
- 本轮没有修改网络、工作区、扩展检查，也没有删除既有审批记录。

## 生效方式

开发模式使用同级引擎 `dist` 时，重启客户端/引擎即可加载新构建。已导入的引擎包是独立版本，此次没有替换已有 `.tgz` 或导入运行时；使用该模式时需重新打包并导入。

当前安全模式存在引擎内存中，重启后恢复配置的默认模式；默认未配置时为标准模式，需重新选择完全访问。
