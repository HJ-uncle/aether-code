## “排队中”的原因及设置

原引擎默认每个主会话同时执行 3 个子代理，超出的任务等待执行名额。之前缺少可见设置入口。

- 入口：设置 → 模型 → 子代理执行 → 子代理并发数量；搜索“排队”也能找到。
- 默认值改为 **5**，可设置 **1–16**，作用于当前引擎，Code 与 Work 共用。
- 调高后立即放行等待任务；调低不打断已在执行的任务。
- 保存后读取引擎实际生效值；保留已有显式配置。
- 旧引擎、受管理的配置、权限失败均显示对应状态，不显示虚假保存成功。
- 远端设置写入只开放单个有效的并发数字字段，保留服务端权限检查。

当前已经运行的引擎需正常重启一次载入新版能力；载入后调整数量即时生效。本轮未重启用户应用或中断用户任务。
