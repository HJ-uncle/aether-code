# Work 建索引入口验收

日期：2026-11-06

Work 输入框的齿轮偏好列表新增首行“代码索引”，位于“当前模型”上方。复用 Code 的引擎索引接口和统一状态逻辑，Code 原页脚入口保留。

- 按当前 Work 会话的工作目录创建代码索引；没有显式目录时交给引擎解析该会话工作区。
- 新建远端任务的首页可使用远端默认目录，已有任务不回退到 Code 的目录。
- 展示创建进度、已建立、失败重试及重新读取状态，防止重复提交；本入口不强制删除或重建已有索引。
- 引擎索引任务为全局单例。其他项目正在索引时显示对应提示，其完成或失败不能冒充当前项目的结果。
- 查询串行执行，只在任务运行时每 1.5 秒继续查询；关闭偏好列表或切换模式后停止，重开读取最新状态。
- 引擎、会话、目录变化时丢弃旧响应。已启动的引擎索引任务不因关闭列表而停止。
- 使用既有主题令牌与偏好行布局；偏好弹层仅滑动过渡，不淡入淡出。

## 验证

- 隔离源码构建包含 node/web typecheck 与 Electron/Vite build。
- 31 条定向纯函数及接口契约测试通过：索引状态、Work 输入契约、远端接口范围。
- 4 项真实 Electron 窗口测试通过：深浅主题及宽窄窗口、真实 IPC/HTTP 的请求目录和次数、失败恢复、关闭后无轮询、会话/模式/引擎切换及迟到响应。
- 窗口测试使用隔离 HTTP 夹具验证调用链和状态，不调用模型，不修改用户会话；底层索引引擎沿用原实现，本轮未更改。
