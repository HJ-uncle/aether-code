# 子代理紧凑阅读与文件改动界面验收

日期：2026-11-06

## 本轮范围

- 子代理详情里的任务指令默认显示两行、靠右的紧凑摘要；展开直接读取完整指令与附件。
- 子代理的回复和思考不再按字符截断，不再出现“继续展开／还有多少字符”。折叠结束后，指令和过程正文从 DOM 卸载。
- 长指令中段收起后保留标题位置；回复复制使用完整文本。
- 主会话继续使用原有消息展示；新增的指令摘要仅用于子代理详情。
- 文件改动页使用两级紧凑工具栏。路径、时间和范围说明放入信息弹层；修改版本保留完整记录，触发按钮缩短为记录序号。
- 保留搜索、增加／删除行数、批量操作、当前文件预览及历史快照警示。
- 修复切换父会话时子代理草稿与阅读状态丢失：缓存不再依附会被卸载的工作区组件，按引擎和会话隔离，引擎变化时同步清空。

## 性能与状态边界

- 折叠正文不挂载 Markdown、图片和附件节点；展开时显示已读取消息的完整文本。
- 历史网络读取沿用原有分页与缓存预算；保留最近 4 个父会话的重内容缓存，更旧的非空草稿按既有策略保留。
- 迟到的历史请求不会写入其他父会话或新引擎的界面。
- 样式复用现有令牌，已核对本轮两份 CSS 的全部变量引用；信息弹层不做淡入淡出。

## 验证结果

- 隔离源码的 `npm run build -- --outDir ...` 通过，包含 Node/Web 两段 typecheck 和 Electron/Vite 构建。
- 29 条现有契约与子代理回放测试通过。
- 3 项真实 Electron 窗口回归通过（单 worker，14.1 秒）。使用独立 HTTP 夹具，执行真实 IPC/HTTP 调用，不调用模型。
  - 超过 12 万字符的指令逐字全文断言、完整思考、95 段最终回复及完整剪贴板内容。
  - 折叠正文不在 DOM；两行摘要尺寸、长文收起定位、子代理／父会话切换记忆及引擎迟到请求隔离。
  - 文件搜索、修改版本、完整路径和时间、当前文件读取请求、批量确认范围；取消确认后无改动写入。
- 子代理深浅主题 × 1440/980 窗口截图、文件改动页浅色 1440 与深色 980 截图已人工检查。
- 本轮 7 个生产文件与测试构建源码的 SHA256 一致。未运行全仓库 E2E。
