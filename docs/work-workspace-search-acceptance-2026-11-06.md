# Work 工作区搜索验收

入口：Work → 工作区 → 搜索。文件和搜索共用工作区左栏，点击命中在右侧预览并定位行与匹配文字。

## 实现范围

- 复用 Code 的搜索控件：关键词、大小写、全字、正则、包含/排除、结果折叠、替换预览。
- 搜索与文件读写绑定当前 Work 会话及工作区，不依赖 Code 选中的目录。
- 切换会话或关闭搜索会使旧请求失效；文件/搜索切换保留当前搜索条件。
- 替换需预览确认，仅处理预览中的文件。文件在预览后变化时拒绝覆盖。
- 长行保留原始列号，文本预览仅滚动自身。正则预览和实际替换统一按行处理，保留原换行。
- 窄栏将搜索选项分行排列；替换预览独立显示，支持取消及 Escape。

## 边界

- 本入口处理文本内容搜索；二进制和未完整读取的文件不会参与替换。
- 跨行正则替换会提示使用编辑器确认。
- 搜索有结果数和遍历容量上限；达到上限或读取失败会明确提示，不能将不完整预览直接应用。
