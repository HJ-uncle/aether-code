# Aether 插件 API 参考项目

- 这是公共文档站的唯一源项目。内容直接写 HTML，禁止用 Markdown 转译作为长期构建依赖。
- `content/*.html` 维护正文；`pages.mjs` 管理导航和输出文件名；`template.html` 和 `assets/` 管理统一布局。每个 h2/h3 必须有稳定且唯一的 id，已有深链接不可随意删除。
- `dist/` 是构建结果，可直接离线打开或部署到任意静态服务器，不能手改。无外部字体、CDN、追踪请求或生产账户依赖。
- 同步实现变更时必须同时核对签名、权限、返回、限制、目标上下文和示例；新接口不能只更新菜单或数量。尚未实现的建议不能写成可用 API。
- 修改前阅读前端根目录 AGENTS.md。先修改并验证正文，再显式 `npm run docs:review` 更新经审阅快照，最后运行 `docs:check`、`docs:test`。不可自动确认未审阅源码。
- 内部维护命令只放 `maintenance.html`，该文件不进入公开 `dist/`。不能把引擎内部接口、脚本或源码路径写给插件使用者。
- CSS 颜色集中于 `assets/tokens.css`，脚本须支持 file://、键盘和深浅主题；搜索/复制失败要如实反馈。
