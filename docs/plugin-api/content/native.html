用 JSON 描述表单和内容，由 Aether 渲染主题、输入和按钮。适合设置和小型操作页面；需要自定义图表、复杂交互时使用 Webview。

页面声明

{ "id": "preferences", "title": "报告设置", "kind": "native", "entry": "ui/preferences.json", "tools": ["save"] }

ui/preferences.json：

{
  "version": 1,
  "root": {
    "type": "stack",
    "children": [
      { "type": "heading", "text": "报告设置" },
      { "type": "input", "bind": "title", "label": "报告标题", "value": "检查报告" },
      { "type": "checkbox", "bind": "includeDetails", "label": "包含详情", "value": true },
      { "type": "button", "label": "保存", "variant": "primary", "action": {
        "tool": "save", "args": { "title": { "$field": "title" }, "details": { "$field": "includeDetails" } }
      } }
    ]
  }
}

此例需要在清单中声明 save 工具。动作结果与错误由页面显示。

组件目录

type 用途 常用属性
text 正文 text
heading 标题 text
markdown 只读 Markdown text；不加载其中的图片或提供外链操作
image 图片 src, alt；src 使用 PNG/JPEG/WebP/GIF 的 base64 data URL
divider 分隔线 无
stack 纵向布局 children, label?
row 横向布局 children, label?
card 分组容器 children, label?
input 单行文本 bind, label, value?, placeholder?
textarea 多行文本 bind, label, value?, placeholder?
select 选择项 bind, label, value?, options
checkbox 开关 bind, label, value?，值为布尔值
button 执行动作 label, action, variant?

所有组件可选 id。输入控件需要 bind 才能编辑；它是当前页面字段名，不是自动保存的配置键。

字段绑定

bind 在整个页面内必须唯一，使用字母开头的字母、数字、下划线，最多 64 字符，不使用 constructor、prototype。文本输入和下拉值为字符串，勾选值为布尔值。

{ "type": "select", "bind": "format", "label": "格式", "value": "markdown", "options": [
  { "label": "Markdown", "value": "markdown" },
  { "label": "纯文本", "value": "text" }
] }

value 是初始值。{ "$field": "format" } 在执行动作时替换为字段当前值，也可用于嵌套参数；不支持表达式计算或执行 JavaScript。

动作

action 在 tool、command 中二选一：

{ "type": "button", "label": "生成报告", "action": { "tool": "generate", "args": { "format": { "$field": "format" } } } }

{ "type": "button", "label": "打开报告", "action": { "command": "open-report" } }

工具必须在页面 tools 白名单中，命令必须在本插件声明。variant 支持 primary、secondary、danger。动作执行期间控件暂时禁用。

限制

不附加固定层数、组件数、文本长度或选项数量限制；大型页面应根据实际渲染成本组织内容。不支持任意 React 模块、JSX、脚本或 HTML 属性注入；目前没有异步数据源、工具结果到组件属性的自动绑定。
