页面订阅用于更新界面，hooks 用于事件触发工具，background 用于周期任务。

events.subscribe(eventName, listener)

订阅当前插件可见的事件，返回订阅 ID。仅页面可用，权限：events.subscribe。

const subscription = await $AE.events.subscribe('agent.completed', event => {
  console.log(event.sessionId, event.payload)
})

eventName 为下表名称或 "*"。listener 接收 { id, type, sessionId, payload, timestamp, sequence }；timestamp 是毫秒时间戳，payload 是事件相关数据。订阅不附加固定数量限制；不再使用时取消订阅，页面销毁时会释放。

events.unsubscribe(id)

释放订阅，不返回业务数据。

await $AE.events.unsubscribe(subscription)

页面不再使用事件时释放；页面关闭或权限撤销也会停止订阅。

事件目录

事件 发生时机
app.started / app.stopping 插件运行服务启动 / 停止，不是页面开关
session.opened / session.closed 会话打开 / 离开
session.changed 当前会话上下文变化
message.created / message.completed 新消息产生 / 消息完成；初次加载历史不作为新消息
workspace.changed 工作区上下文变化
file.changed 已接入的文件操作或回退使文件状态需要重新读取；回退响应未确认时也可能发送，不是任意外部文件监听
editor.selectionChanged 已接入代码预览的选区变化
composer.changed 输入框草稿变化
agent.started 主 Agent 或子代理任务开始
agent.completed / agent.failed / agent.cancelled Agent 完成 / 失败 / 取消

输入与选择等高频事件会合并。事件不是持久消息队列，不保证每个瞬间都送达；完整消息与运行结果使用相应平台 API 读取。

宿主仅保留近期事件历史（最多 256 条或约 8 MiB，超出时淘汰旧条目，并保留最新一条），不会因为当前事件较大而拒绝正常任务。需要长期历史时由插件持久化处理结果；sequence 不作为跨重启的持久游标。

file.changed 是重新读取文件或目录的提示，不是整轮回退成功的回执。部分文件冲突、已撤回或响应丢失时，不应据此删除本地记录、累加修改次数或重新执行写入。文件可能已删除，也可能恢复为较早版本；在绑定当前会话并授权 workspace.read 后重新读取：

const { sessionId } = await $AE.context();
const fileSubscription = await $AE.events.subscribe('file.changed', event => {
  if (!sessionId || event.sessionId !== sessionId) return;
  void $AE.workspace.list({ path: '.' }).then(
    ({ entries }) => console.log('当前目录', entries),
    error => console.error('目录暂时无法读取', error)
  );
});
// 页面不再需要刷新时：await $AE.events.unsubscribe(fileSubscription);

contributes.hooks

指定事件到达时调用插件工具。必要字段：id, title, event, tool；可选 args 及贡献通用字段。权限：events.subscribe。

{
  "permissions": { "requested": ["events.subscribe"] },
  "contributes": {
    "hooks": [{ "id": "completed", "title": "完成后检查", "event": "message.completed", "tool": "review", "scope": "session" }]
  }
}

工具从 args.event 取得 { id, type, sessionId, payload, timestamp }。按事件 ID 去重，避免事件处理再次无限触发同类操作。

同一 hook/会话忙碌或 250ms 冷却未结束时会跳过，不排队补发；不附加固定并发数或普通 hook 执行时限。退出事件只有短暂收尾时间，不用于保存唯一业务数据。开发预览不自动注册 hooks。

contributes.background

运行可在重启后恢复的周期工具。必要字段：id, title, tool, intervalMs；可选 args, runOnStartup。权限：background.run。

{
  "permissions": { "requested": ["background.run"] },
  "contributes": {
    "background": [{ "id": "sync", "title": "定期同步", "tool": "sync", "intervalMs": 60000, "runOnStartup": true }]
  }
}

intervalMs 为 1 秒至 7 天（毫秒）。后台任务独立于会话，不能声明 scope: "session" 或要求会话/工作区存在。工具实际调用的 AI、设置等能力仍需要各自权限。

同一任务不重叠；不附加插件或账户的固定并发数。错过多个周期只补一次，任务应允许安全重试。发布、启用并授权后调度，开发预览不自动启动持久任务。

调度由承载插件的引擎执行。检测到有效后台任务时，关闭桌面窗口会进入托盘；桌面内置引擎随应用真正退出而停止，下次引擎启动恢复。连接外部或远端引擎时，桌面退出不等于该引擎停止，任务是否继续取决于它自身的运行状态。停用、卸载插件或撤销权限会停止后续调度；后台任务不会唤醒已关机的设备。
