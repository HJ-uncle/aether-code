以下方法在 Aether 承载的 Webview 插件页面中通过 window.$AE 使用，也适用于开发预览和内置浏览器里的插件标签。普通网页和 Node 工具没有这些页面方法。除 services.subscribe 返回取消函数外，方法均返回 Promise；失败抛出错误。

页面调用不附加插件专属参数容量限制，遵循平台传输和系统资源配置。长结果优先使用流式能力。

invoke(tool, args?)

调用本页面 tools 白名单中的本地工具。

const { result } = await $AE.invoke('count', { text: '你好🍎' })

tool 是工具名；args 是参数对象，默认 {}。返回 { result, artifacts, stderr, durationMs, plugin: { id, revision, hash } }，业务结果在 result。

navigate(page)

打开本插件声明的页面，page 为局部页面 ID。完成后返回 null。

await $AE.navigate('preferences')

commands.execute(id, args?)

执行本插件的声明命令。args 默认 {}，同名字段覆盖命令的默认参数。

await $AE.commands.execute('review', { title: '本次检查' })

工具命令返回工具回执；页面命令打开页面并返回 null。命令接收当前页面绑定的会话与目标上下文。

download(input)

打开保存对话框，将内容保存到用户选择的位置。

const { saved } = await $AE.download({
  fileName: 'report.md', content: '# 检查结果\n', encoding: 'utf8'
})

fileName 是文件名，不能带目录；content 为字符串；encoding 为 utf8（默认）或 base64。返回 { saved, bytes? }，取消时 saved: false，不返回本机路径。

services

管理本插件通过 contributes.services 声明的服务。会话作用域中运行或等待处理的服务显示在当前会话标题栏的「服务」中；完成、停止或失败的记录在同一弹层的「服务历史」中查看。未运行的 idle 服务不显示在这两个列表中，仍可通过 SDK 读取和启动。参数 id 使用 contributes.services[].id，不要传带平台前缀的快照 ID。

服务实例遵循声明的 scope，全局服务可通过插件页面和 SDK 管理。服务历史按会话区分，历史摘要不等同于可继续操作的服务实例。底部「活动」与「历史」承载通知，不汇总服务记录。

方法 用途 返回
services.get() 读取当前可见服务 服务快照数组
services.start(id, args?) 调用服务的 tool；合并默认参数 更新后的快照数组
services.stop(id) 调用 stopTool 更新后的快照数组
services.refresh(id) 调用 statusTool 更新后的快照数组
services.subscribe(listener) 接收快照变化 同步返回取消函数 
let services = await $AE.services.get()
const unsubscribe = $AE.services.subscribe(next => { services = next })
await $AE.services.start('timer', { seconds: 60 })
// 页面组件不再使用订阅时调用：
unsubscribe()

快照包含 id, pluginId, instanceId, revision, label, status, updatedAt，以及可选 detail, sessionId, notification。id 是不透明实例标识。状态为 idle / running / waiting / completed / stopped / error。没有声明 stopTool 或 statusTool 时，对应操作失败。

ui.dialog(input)

显示原生消息或确认对话框。权限：ui.dialogs。

const { canceled } = await $AE.ui.dialog({
  kind: 'question', title: '生成报告', message: '现在生成当前会话报告？',
  buttons: ['生成', '取消']
})

kind 可为 info（默认）、warning、error、question；title、message 必填；buttons 默认 ['好']，最多 4 个。返回 { response, canceled }：response 是按钮索引，多个按钮时最后一个作为取消按钮。当前不提供文本输入框。

ui.notify(input)

发送应用内通知并请求显示系统通知。权限：ui.notifications。

const { shown } = await $AE.ui.notify({ title: '处理完成', body: '已生成 3 份报告' })

title 最多 120 字符，body 最多 2000 字符。返回 { shown }，表示系统通知请求是否可显示，不代表用户已阅读。系统通知每插件每窗口最多 5 次/分钟。

应用内通知在当前引擎的全局「活动」中显示，切换会话后仍可见，并共享未读、已读状态。发送通知的权限校验仍使用调用页面绑定的会话身份。系统通知不可用时，应用内通知仍会显示。

已读通知进入底部「历史」，与完成服务的摘要合计最多在本地保留 100 条，摘要详情最多 1,024 字符。历史按引擎连接与账户隔离，切换会话或重载界面后仍可查看；未读通知保存在当前运行期间的内存中。

ui.clipboard

读写系统文本剪贴板。权限：ui.clipboard。

const { text } = await $AE.ui.clipboard.read()
await $AE.ui.clipboard.write('报告摘要')

read() 返回完整 { text }；write(text) 返回 { written: true }。文本读写不附加插件专属长度限制。不支持图片或文件剪贴板。

ui.editor

操作当前会话中已接入插件能力的代码预览。权限：ui.editor。需要存在唯一可用目标；普通成果文本、PDF、图片等预览不是此接口的编辑目标。

方法 参数 返回与行为
ui.editor.get() 无 { path, content, selectionText, range, readOnly }
ui.editor.reveal({ line, column? }) 从 1 开始的行列，列默认 1 定位、滚动并聚焦；返回 { revealed: true, lineNumber, column }
ui.editor.replaceSelection(text) 替换文本 当前代码预览为只读，此调用报错；写文件使用 workspace.write 
const editor = await $AE.ui.editor.get()
await $AE.ui.editor.reveal({ line: 12, column: 1 })

菜单命令需要开菜单时的选区，读取 context().selectionText；editor.get() 读取执行当时的实时选区。

ui.composer

操作当前绑定会话的输入框。权限：ui.composer。

方法 返回与行为
ui.composer.get() { text, mentions, sessionId }；mentions 为现有引用信息
ui.composer.set(text) 替换草稿文本、保留已有引用标签，返回 { text, mentions }
ui.composer.insert(text) 在草稿末尾追加文本、保留引用，返回 { text, mentions }
ui.composer.submit() 按输入框当前可用动作提交，返回 { dispatched: true } 
await $AE.ui.composer.insert('\n请同时检查无障碍支持。')

insert 不按光标位置插入。submit 表示提交动作已派发，不代表模型已经完成；草稿不可提交或目标已关闭时会报错。当前 API 不提供创建附件或自定义引用标签的方法。

页面环境

页面不需要导入 SDK。脚本、样式内联，图片用 data URL 或页面生成的 blob；页面不直接请求外网，网络操作放到插件工具中。表单提交事件应调用 event.preventDefault()，再调用 SDK。

主题自动同步 color-scheme、data-appearance 和以下 CSS 变量，切换主题不会重载页面：

/* 示例：继承平台配色 */
main { background: var(--bg-surface); color: var(--fg); }
button { background: var(--accent); color: var(--accent-fg); }

可用变量：--bg-app、--bg-surface、--bg-elevated、--bg-input、--bg-hover、--bg-active、--fg、--fg-strong、--fg-muted、--fg-faint、--accent、--accent-hover、--accent-fg、--accent-soft、--border、--border-strong。
