用插件扩展 Aether 的会话、工作区和界面，并调用平台已有的 AI、Agent、Skills、MCP 与知识库能力。本文对应 apiVersion: 1。

开始使用

在「插件 → 开发模式」打开自己的插件目录，按需绑定会话和授权，修改后刷新即可调试。也可以在会话中添加 @插件管理，让 AI 从模板创建工程。

  • 插件文件与清单：三个文件的完整示例、工具输入输出、调试与导入。
  • 权限：声明权限、用户授权和适用范围。
  • Agent 示例：启动任务、读取状态、取消与接续，以及可用的基础工具范围。

验证页面插件时，除了工具的输入输出，还要实际走通点击、AI 返回、结果渲染和导出。默认脚手架的 Node 测试不覆盖页面；使用固定模型回复的测试也不能替代真实模型验证。

平台 API

以下接口可用于插件页面和平台启动的 Node 工具。$AE 自动提供，无需导入，也无需让用户重复填写模型密钥。

能力 API 用途
上下文 context() 当前会话、工作区、消息或文件目标
模型 models.list() 平台可用模型
AI ai.run()（非流式） · ai.stream()（流式输出） 等待完整结果，或逐段接收正文
会话 session.messages() 分页或按 ID 读取消息
Skills list() · get() 技能目录与说明
Agent tools() · list() · run()（后台任务） · stream()（流式输出） · status() · cancel() 六类内置工具、后台任务、流式进度与续跑
工作区 list() · read() · write() 目录与文本文件
知识库 list() · search() · get() · create() · update() 知识检索与写入
MCP list() · tools() · call() 已启用服务、工具参数与调用
插件设置 get() · set() 本插件的配置
通用调用 call() 按能力名调用公开方法 
const { skills } = await $AE.skills.list()

上述示例需要在清单申请 skills.read，并由用户授权。

页面 API

以下接口用于 Aether 承载的 Webview 插件页面，包括开发预览和内置浏览器中的插件标签。

API 用途
invoke() 调用本页面声明的插件工具
navigate() 打开本插件页面
commands.execute() 执行本插件命令
download() 让用户选择位置保存文件
services 查询、启动、停止、刷新和订阅服务
ui.dialog() 消息与确认弹窗
ui.notify() 应用内及系统通知
ui.clipboard 文本剪贴板
ui.editor 已接入代码预览的选择与定位
ui.composer 读取、修改和提交草稿
events.subscribe() · unsubscribe() 生命周期事件

界面挂载

在清单 contributes 中声明，字段与示例见 挂载区域。

声明 用途
pages 工具表单、Webview、原生组件页面
navigation 左侧导航入口
workspaceTabs 右侧工作区页签
commands 命令面板与快捷键
menus 消息、会话、文件、编辑器、服务、输入框和顶部菜单
views 消息、输入框和工作区内嵌页面
statusBar 底部状态栏入口
settings 插件设置页
editorDecorations 代码预览标记与提示
services 插件服务，以及会话工作区入口中的运行状态与服务历史
hooks 事件触发工具
background 可恢复的周期任务

原生组件

原生组件参考：text、heading、markdown、image、divider、stack、row、card、input、textarea、select、checkbox、button。

使用 JSON 声明即可继承平台的主题和交互；复杂自定义界面使用 Webview。
