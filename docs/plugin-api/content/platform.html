$AE 由 Aether 注入受信插件页面和宿主启动的 Node 工具。以下方法在两者中通用，不需要插件保存模型密钥。普通网页和独立启动的 Node 程序没有此对象。

模块 方法
上下文 context
模型与 AI models.list、ai.run（非流式）、ai.stream（流式输出）
会话 session.messages
Skills skills.list、skills.get
Agent agents.list、agents.tools、agents.run（后台任务）、agents.stream（流式输出）、agents.status、agents.cancel
工作区 workspace.list、workspace.read、workspace.write
知识库 knowledge.list、knowledge.search、knowledge.get、knowledge.create、knowledge.update
MCP mcp.list、mcp.tools、mcp.call
插件设置 settings.get、settings.set
通用调用 call

通用约定

  • 所有方法返回 Promise。失败时会拒绝，可读取 Error.message；不要依赖错误对象具有 code 属性。
  • 除 context() 外，能力必须在 manifest.permissions.requested 中声明，并获得用户对当前插件版本的授权。声明不等于授权。
  • 业务参数和返回值通过 JSON 传递；Args 表示 Record<string, unknown>，实际值应可序列化为 JSON。流式调用的第二参数 onEvent 和 signal 由 SDK 在本地处理。按签名传参，不添加未声明字段。
  • 会话、工作区与用户身份由宿主绑定，不能通过参数切换。版本变化、停用或撤销权限后，后续调用可能失败，需要刷新或重新授权。
  • 插件不额外设置调用时长、结果大小或并发配额。执行沿用平台、所选模型及系统资源策略；请求传输遵循平台通用配置。使用 AbortSignal 主动取消不再需要的任务。
  • 长输出使用 stream 接口；SDK 等待消费者处理后再接收后续事件，避免在页面排积大量待处理回调。
  • 权限开关控制 $AE 宿主能力。Node 工具是本机代码，这些开关不是操作系统沙箱。

例如，只读取当前会话并调用 AI 的插件可以声明：

{ "permissions": { "requested": ["session.read", "models.read", "ai.run"] } }

$AE.context()

读取此次页面或工具调用的宿主上下文。

$AE.context(): Promise<{
  sessionId: string | null;
  workspacePath: string | null;
  pluginId: string;
  revision: number;
  messageId?: string;
  messageRole?: string;
  filePath?: string;
  selectionText?: string;
  targetId?: string;
  engineReady?: boolean; // 页面附加字段
}>

参数：无。权限：不需要单独声明能力。

返回：插件标识和版本，以及宿主提供的会话、工作区和操作目标。全局入口的 sessionId、workspacePath 可以为 null；消息、文件、选区字段只在相应入口提供。上下文中的路径或标识本身不授予读写权限。

const { sessionId, selectionText } = await $AE.context();

$AE.models.list()

列出平台已配置且启用的模型，供用户选择。

$AE.models.list(): Promise<{
  models: Array<{ id: string; modelId: string; name: string; provider: string }>;
}>

参数：无。权限：models.read。

返回：id 是平台模型配置 ID，modelId 是提供方模型名，name 是显示名称。列表不包含密钥或连接凭据；建议将选中的 id 传给 AI 或 Agent，以区分同名模型配置。

const { models } = await $AE.models.list();

$AE.ai.run(args) · 非流式生成

使用平台模型生成文本，等待生成结束后一次性返回完整结果。需要边生成边显示时，使用 ai.stream() 流式输出。

$AE.ai.run(args: {
  modelId: string;
  prompt?: string;
  messages?: Array<{ role: 'user' | 'assistant'; content: string }>;
  systemPrompt?: string;
  maxTokens?: number;
}): Promise<{
  text: string;
  model: string;
  usage: { inputTokens?: number; outputTokens?: number };
}>

权限：ai.run；只有调用模型目录时才另需 models.read。

参数：modelId 接受已启用模型的配置 ID 或模型名，为 1–4,096 字符。prompt 与 messages 至少提供一种；两者同时提供时，prompt 追加为最后一条用户消息。消息、提示词不设插件专属长度上限；maxTokens 为正整数，省略时沿用平台输出配置。实际上下文和输出仍取决于所选模型。

返回：完整可见正文、实际模型名称和 token 用量。空正文、输出截断或未完成的工具调用会报错，不会伪装成完整结果。此方法不自动读取会话，也不执行工具；需要工具循环时使用 agents.run。模型调用产生正常费用。

const { text } = await $AE.ai.run({ modelId, prompt: '检查这份需求：' + requirement });

$AE.ai.stream(args, options?) · 流式输出

通过 onEvent 逐段接收 text-delta 事件，将每段 event.text 追加到页面，即可边生成边显示正文。生成结束后，Promise 返回与 ai.run() 相同的完整结果。页面和宿主启动的 Node 工具均可使用。

$AE.ai.stream(args: AetherPluginAIInput, options?: {
  signal?: AbortSignal;
  onEvent?: (event: AetherPluginStreamEvent<AetherPluginAIResult>) => void | Promise<void>;
}): Promise<AetherPluginAIResult>

type AetherPluginStreamEvent<R = unknown> =
  | { type: 'started'; runId?: string; childSessionId?: string; model?: string }
  | { type: 'text-delta'; text: string; runId?: string }
  | { type: 'tool-start' | 'tool-end'; toolName: string; toolCallId?: string;
      runId?: string; success?: boolean; durationMs?: number }
  | { type: 'pending'; runId: string; childSessionId: string;
      pending: AetherPluginAgentPending }
  | { type: 'complete'; result: R }
  | { type: 'error'; error: { code: string; message: string } };

权限与参数：与 ai.run 相同；AetherPluginAIInput、AetherPluginAIResult 是生成的 aether-sdk.d.ts 中的输入和返回类型。onEvent 按顺序处理事件，可返回 Promise。文本事件只是增量，不是累计全文；单次 AI 不发工具事件，也不发模型内部推理。提供方未报告的用量字段缺省，不应当作零。

完成与失败：complete 才表示成功，Promise 返回完整结果。错误发 error 并拒绝 Promise；取消、断线、超时或消费者异常也会拒绝，断线时可能收不到错误事件。不能把已经显示的部分正文当作完整结果。用 AbortController.abort() 停止；页面关闭或开发会话关闭也会取消其流式请求，普通后台 agents.run 不受页面流关闭影响。

接收节奏：SDK 按顺序等待每次 onEvent 完成，再推进接收。不因回调超过 30 秒、输出超过旧容量或事件数量而取消。Promise 等全部事件处理完成后才结束。需要停止时调用 abort()，页面关闭、权限撤销及连接断开也会结束请求。

const controller = new AbortController();
const preview = document.createTextNode('');
output.replaceChildren(preview);
stopButton.onclick = () => controller.abort();
try {
  const result = await $AE.ai.stream({ modelId, prompt: requirement }, {
    signal: controller.signal,
    onEvent(event) {
      if (event.type === 'text-delta') preview.appendData(event.text);
    }
  });
  output.textContent = result.text;
  status.textContent = '已完成';
} catch (error) {
  status.textContent = controller.signal.aborted ? '已停止，内容未完成' : error.message;
}

$AE.session.messages(args?)

分页读取当前绑定会话的显示消息，或按消息 ID 读取所选消息。

$AE.session.messages(args?: {
  offset?: number;
  limit?: number;
  ids?: string[];
}): Promise<{
  messages: SessionMessage[];
  total: number;
  nextOffset: number | null;
  revision?: string;
}>

type SessionMessage = {
  id?: string;
  role: 'user' | 'assistant' | 'tool' | 'system';
  content: string | unknown[];
  createdAt?: number;
  metadata?: unknown;
  reasoningContent?: string;
  toolCall?: { id: string; name: string; args: Args };
  toolCallId?: string;
  toolName?: string;
  tokens?: number;
  usage?: Record<string, number> | null;
  modelId?: string;
};

权限：session.read；必须绑定会话。

参数：offset 为从 0 开始的整数历史偏移，默认 0；limit 为正整数，默认 50。ids 每个为 1–4,096 字符，提供后优先于分页参数；只返回当前会话中找到的消息，缺失 ID 被忽略。

返回：分页时 total 是历史消息总数，nextOffset: null 表示结束；按 ID 读取时 total 是实际返回数量，nextOffset 恒为 null。revision 可能缺省。content 可能是内容块数组，附件信息可能在内容块或 metadata 中；不要把所有消息当成纯文本。返回值不包含模型请求的隐藏输入副本。

const page = await $AE.session.messages({ limit: 50 });
const selected = await $AE.session.messages({ ids: selectedMessageIds });

Skills

两个方法均需 skills.read。绑定会话时包含其工作区可用技能；没有会话时读取平台默认技能集合。读取技能说明不等于获得执行其脚本的权限。

$AE.skills.list()

列出当前可用技能的摘要。

$AE.skills.list(): Promise<{
  skills: Array<{
    id: string; name: string; description: string;
    scope?: 'global' | 'project'; builtin?: boolean;
  }>;
}>

参数：无。返回：技能标识、名称、描述和可选来源字段；不包含技能全文。

const { skills } = await $AE.skills.list();

$AE.skills.get(args)

读取一个可用技能的完整说明文本。

$AE.skills.get(args: { id: string }): Promise<{ id: string; name: string; content: string }>

参数：id 使用 skills.list() 返回的技能 ID，为 1–4,096 字符。返回：技能名称和全文。技能不存在、已停用或内容不可读时会报错。

const { content } = await $AE.skills.get({ id: skillId });

Agent

任务方法必须绑定会话，仅访问当前插件在该会话中创建的任务。agents.tools() 可在没有会话时查询基础工具目录。它们不提供平台全部 Agent 的目录，也不提供向运行中任务追加消息的方法。

分析已经拿到的消息或文本，用 ai.stream() 边生成边显示，或用 ai.run() 等待完整结果。需要模型读写工作区并连续调用工具时，用 agents.stream() 接收流式进度，或用 agents.run() 启动后台任务。会话消息先由插件代码读取，再作为任务上下文传入。

返回的任务快照使用以下结构；result 是当前结果摘要或已有部分输出，不是完整执行记录：

type AgentRun = {
  runId: string;
  childSessionId: string;
  pluginId: string;
  sessionId: string;
  status: 'queued' | 'running' | 'cancelling' | 'succeeded'
    | 'failed' | 'cancelled' | 'blocked' | 'interrupted';
  description: string;
  modelId: string;
  createdAt: number; // Unix 毫秒
  updatedAt: number; // Unix 毫秒
  result: string;
  usage: {
    inputTokens?: number; outputTokens?: number; totalTokens?: number;
    cacheReadTokens?: number; cacheWriteTokens?: number;
    estimated?: boolean; unknown?: boolean;
  };
  toolCount: number;
  pending: AgentPending[]; // 当前等待用户答复的请求；没有时为空数组
  error?: { code: string; message: string };
};
type AgentPending = {
  requestId: string; toolCallId: string; toolName: string;
  args: Record<string, unknown>;
  kind: 'ask' | 'permission'; status: 'pending' | 'answered';
  question?: string; options?: unknown[]; description?: string;
  messageId?: string; output?: string;
  displaySummary?: {
    source: 'durable_approval'; fields: Array<'args' | 'question' | 'description' | 'options'>;
    originalArgsBytes?: number; omittedArgumentKeys?: number;
  };
  sourceChangeWait?: Record<string, unknown>;
};

pending 是展示信息，供页面提示“等待用户确认”或“等待补充信息”。较大的确认参数可带 displaySummary；完整操作由平台保存。该对象不包含可执行的封存操作，不能拿它替代用户答复。

$AE.agents.list(args?)

分页列出当前插件与会话的 Agent 任务。

$AE.agents.list(args?: { cursor?: string; limit?: number }): Promise<{
  runs: AgentRun[]; nextCursor: string | null;
}>

权限：agents.read。参数：显式 limit 为 1–50 的整数；当前省略时默认取 64，建议显式传入。cursor 最长 4,096 字符，原样使用上次返回的 nextCursor，不要自行构造。返回：任务快照和下一页游标，null 表示没有下一页。

const { runs, nextCursor } = await $AE.agents.list({ limit: 20 });

$AE.agents.run(args) · 后台任务

启动或接续后台 Agent 任务，在任务被接纳后返回快照。任务会继续调用已授权工具；通过 agents.status() 查询进度和最终结果。需要正文增量与工具进度回调时，使用 agents.stream()。

$AE.agents.run(args: {
  modelId: string;
  task: string;
  description?: string;
  resumeRunId?: string;
  identity?: { name?: string; description?: string };
  systemPrompt?: string;
  skillIds?: string[];
  mcpServerIds?: string[];
  disabledTools?: string[];
  customTools?: Array<{ name: string; tool: string }>;
}): Promise<AgentRun>

权限：agents.manage，以及任务实际需要的其他平台能力；读取任务状态另需 agents.read。

参数：modelId 接受已启用模型的配置 ID 或模型名，最长 256 字符。task 是非空需求；description 是可选的任务摘要。resumeRunId 必须属于当前插件与会话，是该 childSessionId 的最新执行，并处于 succeeded、failed、cancelled、blocked 或 interrupted 状态。同一子会话有活动执行时不能再次接续，也不能从过期执行分叉。有待答复的请求时，应先由用户答复或取消；不能用新任务跳过确认。

返回：任务接纳后的快照，返回不代表任务已完成。用 runId 查询后续状态。接续会创建新 runId，复用原 childSessionId 和上下文；要求原工作区仍匹配，可调整身份、提示词、挂载与工具配置，实际执行始终检查当前授权和用户禁用名单。

运行策略：不增加插件专属 Agent 并发配额或任务时限。Agent 复用平台工具注册、模型执行与安全检查。工作区变化、插件停用或撤销授权会阻止后续执行。调用使用正常模型额度。

工具授权：agents.manage 管理任务；engine.tools 开放下方六类、33 个内置工具，执行沿用绑定会话的安全策略。agents.tools() 返回准确名称、参数及可用性；未授权或已禁用的工具不会提供给模型。

内置工具仅包含文件、命令、交互与计划、搜索、子代理、Skill。工具按需加载，检查 available 和 reason 了解当前授权与调用入口状态。Office、浏览器、工作台和成果工具不在插件 Agent 的内置范围中。

插件 Agent 拥有独立的执行与会话记录，工作区继承绑定会话。其子代理遵循相同工具范围、用户禁用名单和当前授权。插件代码可直接使用已授权的 $AE 接口读取会话、知识库或设置，再把所需内容放入 task；这些接口不会自动包装成 Agent 工具。

const run = await $AE.agents.run({ modelId, task: '读取当前工作区的 README.md 并生成需求检查报告。' });

身份、提示词与挂载

identity.name 与 identity.description 设置身份；systemPrompt 设置专用指令；task 是本轮需求。提示词不授予权限。没有插件专属提示词长度限制。

skillIds 使用 skills.list() 返回的 ID，需要 skills.read；技能全文加载进系统上下文。mcpServerIds 使用 mcp.list() 返回的 ID，需要 mcp.read、mcp.invoke；使用服务器真实工具定义。不另限挂载数量或技能总字节数。脚本执行还需平台工具及对应安全策略。

显式数组选择挂载范围，[] 清空该类挂载。首次运行省略数组时不自动挂载外部 Skill 或 MCP；插件代码可先调用 $AE.skills.list()、$AE.mcp.list() 选择资源。续跑省略配置继承原任务；显式传入新配置会更新，不需要新建会话。撤权、停用和用户禁用始终优先。

const run = await $AE.agents.run({
  modelId,
  identity: { name: '需求审查员', description: '查找遗漏与相互冲突的约束' },
  systemPrompt: '引用可验证依据，区分事实和建议。',
  task: '检查当前工作区的需求，生成审查报告。',
  skillIds: selectedSkillIds,
  mcpServerIds: selectedServerIds
});

$AE.agents.tools(args?)

查询真实工具名称、说明、JSON Schema、来源和当前可用状态。需要 agents.read；不启动模型、不执行工具。

$AE.agents.tools(args?: AetherPluginAgentConfiguration): Promise<{
  tools: Array<{
    name: string; description: string; parameters: Args;
    source: 'engine' | 'skill' | 'mcp' | 'plugin';
    enabled: boolean; available: boolean; reason?: string;
  }>;
}>

args 接受与 run 相同的身份、提示词、skillIds、mcpServerIds、disabledTools、customTools。不接受任务或模型字段。可先查询、再把同一配置传给 run/stream。enabled 表示配置是否启用；available 表示当前授权和调用入口是否支持，不保证命令或语言服务等运行依赖已就绪；不可用原因在 reason。

用户在插件管理 → 权限 → Agent 工具中可搜索和逐项开关。用户禁用名单独立保存；插件设置和请求不能把用户禁用的工具重新开启。工具开关控制准确的工具名：关闭 write_file 不会同时关闭 execute_cmd，也不改变插件代码通过 $AE.workspace.write() 或 Node 进行文件访问的权限。需要收回某类访问时，同时调整对应能力和工具。disabledTools 可追加本次任务不需要的工具，执行时同样拦截，不能用 load_tools 绕过。

const configuration = {
  disabledTools: ['execute_cmd', 'delete_file'],
  customTools: [{ name: 'inspect_requirement', tool: 'review' }]
};
const { tools } = await $AE.agents.tools(configuration);
const enabled = tools.filter(tool => tool.enabled && tool.available);
const run = await $AE.agents.stream({ modelId, task: '审查需求并汇总结果', ...configuration }, {
  onEvent(event) { if (event.type === 'text-delta') output.append(event.text); }
});

customTools 的 tool 引用当前插件 manifest.tools 已声明的本地 Node 工具，name 是提供给模型的名称。说明、参数和执行入口取自清单，不需重复编写 schema。名称须满足模型工具命名规则且不能冲突；执行使用相同插件版本、绑定会话、工作区和实时授权。工具返回的产物按正常插件产物处理。不接受可执行函数字符串。

插件代码与显式扩展

$AE.session、$AE.ai、$AE.workspace、$AE.knowledge、$AE.settings 等接口继续供插件代码直接调用，并分别检查授权；授权不会自动向 Agent 注入 ae_* 工具。

开发者可用 mcpServerIds 显式挂载外部 MCP，或用 customTools 挂载本插件声明的工具。这些是开发者选择的扩展，参数与执行仍按各自权限校验。

六类内置工具 · 33 个

以下为插件 Agent 的完整内置范围。engine.tools 授权后按需加载，用户仍可逐项禁用。工具目录以 agents.tools() 返回的实际状态为准；主会话 Agent 的工具配置与本表不同。

已授权、未禁用工具且未挂载扩展的新任务，首轮向模型提供 16 个工具定义；其余通过 load_tools 按需加载。续跑历史、禁用设置与显式扩展会影响本轮实际定义数量。

$AE.agents.stream(args, options?) · 流式输出与进度

通过 onEvent 逐段接收 text-delta 正文和工具执行进度；本次流结束后，Promise 返回 AgentRun。参数、身份配置、挂载和权限与后台任务 agents.run() 相同；回调及取消方式与 ai.stream() 相同。

$AE.agents.stream(args: AetherPluginAgentInput,
  options?: AetherPluginStreamOptions<AetherPluginAgentRun>
): Promise<AetherPluginAgentRun>

started 提供本段 runId 和 childSessionId；text-delta 是本次运行的可见正文，tool-start / tool-end 只包含工具名和进度，不包含参数、工具结果或内部推理。失败终态拒绝 Promise。最终 result 仍是任务快照中的有界摘要；需要完整本次显示正文时自行拼接增量。此接口启动或续跑任务，不能订阅一个已在运行的 runId。

用户确认与问答：pending 事件包含 { type: 'pending', runId, childSessionId, pending: AgentPending }。插件页面调用 agents.stream() 时，Aether 在插件页面外显示确认或问答卡；用户答复后继续同一个 Promise 和事件回调，开发者无需拼接第二次调用。后续 started 提供新 runId，childSessionId 不变。取消请使用同一个 AbortController，或保存最新 runId 调用 agents.cancel()。若收到源码正在变化的提示，插件宿主提供手动重新检查或停止，不自动替用户选择。

后台与 Node：后台 agents.run() 通过 status() 返回 blocked 和 pending；Node 的 agents.stream() 在本段等待用户时返回相同快照。因此 complete 表示这次调用结束，仍须检查 result.status；只有 succeeded 表示任务成功。Node 和插件脚本不能代替用户批准；需要交互的任务优先从插件页面调用 agents.stream()。页面的宿主确认流程不会把中间 blocked 当作最终结果发给页面回调。

流式运行不设插件专属时限；关闭页面、停止、撤权或断开连接会取消本次 Agent，已完成的外部操作不会回滚。需要跨页面长时间运行时使用 agents.run() 并查询 status()。

let runId;
const run = await $AE.agents.stream({ modelId, task: '检查工作区并保存审查报告。' }, {
  signal: controller.signal,
  onEvent(event) {
    if (event.type === 'started') runId = event.runId;
    if (event.type === 'text-delta') preview.appendData(event.text);
    if (event.type === 'pending') status.textContent = '等待用户答复';
    if (event.type === 'tool-start') status.textContent = '正在使用 ' + event.toolName;
  }
});

示例：检查工作区并保存报告

在清单中声明并授权以下能力，绑定工作区后运行。selectedMessageIds 是页面上用户选择的消息 ID；插件先读取这些消息，再交给 Agent 使用内置文件工具检查工作区。模型使用配置 id。

{ "permissions": { "requested": ["models.read", "session.read", "agents.manage", "agents.read", "engine.tools"] } }

const { models } = await $AE.models.list();
if (!models.length) throw new Error('请先配置并启用模型');
const modelId = models[0].id;
const { messages } = await $AE.session.messages({ ids: selectedMessageIds });
let run = await $AE.agents.run({
  modelId,
  description: '检查工作区需求',
  task: '根据以下所选会话内容，列出当前工作区、读取 README.md，检查需求是否完整。'
    + '使用文件工具把报告写入 reports/review.md，并说明依据。\n'
    + JSON.stringify(messages)
});
// 保存 runId，页面重开后也可以查询本插件在同一会话中的任务。
const runId = run.runId;
const pending = new Set(['queued', 'running', 'cancelling']);
for (let attempt = 0; attempt < 60 && pending.has(run.status); attempt++) {
  await new Promise(resolve => setTimeout(resolve, 1000));
  run = await $AE.agents.status({ runId });
}
if (run.status === 'succeeded') {
  console.log(run.result);
} else if (pending.has(run.status)) {
  console.log('任务仍在运行，稍后使用 runId 查询：', runId);
} else {
  console.log(run.status, run.error?.message || run.result);
}

示例最多等待约一分钟；停止查询不会取消任务。用户点击取消时调用 agents.cancel({runId})。已结束后可传入 resumeRunId 接续，继续查询新返回的 runId。可在生成的 aether-sdk.d.ts 中使用 AetherPluginAgentRun 检查任务返回字段。

// 使用最新执行的 ID 接续；后续查询和再次接续都更新为新返回的 ID。
run = await $AE.agents.run({
  modelId,
  resumeRunId: run.runId,
  task: '根据已有检查结果补充验证并更新报告。'
});

插件接口仍要求明确的 task，通过原插件宿主接续并检查当前权限。会话界面的「继续」控制不替代插件接口，也不能接管插件 Agent 或自动答复其待处理确认。

$AE.agents.status(args)

读取指定 Agent 任务的最新快照。

$AE.agents.status(args: { runId: string }): Promise<AgentRun>

权限：agents.read。参数：runId 为任务返回的 UUID。返回：状态、结果摘要、用量和工具计数；任务不属于当前插件与会话时会报错。

const current = await $AE.agents.status({ runId: run.runId });

$AE.agents.cancel(args)

请求取消当前插件与会话中的指定任务。

$AE.agents.cancel(args: { runId: string }): Promise<AgentRun>

权限：agents.manage。参数：runId 为任务返回的 UUID。返回：取消请求处理后的快照；以返回状态或后续 status() 查询确认最终状态。取消不撤销任务已经完成的文件写入或其他操作。

const stopped = await $AE.agents.cancel({ runId: run.runId });

工作区

必须绑定会话。路径相对当前绑定工作区；SDK 拒绝越界路径，以及经符号链接或联接点访问文件。绝对路径也必须位于同一工作区。切换工作区后旧绑定不能继续使用。

$AE.workspace.list(args?)

读取工作区内一个目录的直接子项。

$AE.workspace.list(args?: { path?: string }): Promise<{
  entries: Array<{ name: string; type: 'file' | 'directory' | 'link'; path: string }>;
}>

权限：workspace.read。参数：path 默认 '.'，最长 4,096 字符。返回：子项名称、类型和相对工作区路径，路径使用 /。不递归；link 项可以列出，但不能经由它继续读写。

const { entries } = await $AE.workspace.list({ path: 'docs' });

$AE.workspace.read(args)

以 UTF-8 文本读取一个工作区文件。

$AE.workspace.read(args: { path: string }): Promise<{ path: string; content: string; size: number }>

权限：workspace.read。参数：path 为文件路径，最长 4,096 字符。返回：请求路径、文本和文件字节数；支持普通文本文件，不提供二进制或分段读取。

const { content } = await $AE.workspace.read({ path: 'docs/requirements.md' });

$AE.workspace.write(args)

以 UTF-8 文本创建或覆盖一个工作区文件。

$AE.workspace.write(args: { path: string; content: string }): Promise<{ path: string; written: boolean }>

权限：workspace.write。参数：path 最长 4,096 字符，content 为文本，可以为空。返回：请求路径与写入结果。缺少的父目录会创建，已有文件整体覆盖；没有追加、删除或重命名选项。

await $AE.workspace.write({ path: 'reports/review.md', content: report });

知识库

知识数据限当前用户空间，不要求绑定会话；knowledge.read / knowledge.write 分别控制下列读写方法。时间字段使用 Unix 秒。

type KnowledgeBase = {
  id: string; revision: number; tenantId: string;
  name: string; description: string; documentCount: number;
  createdAt: number; updatedAt: number;
};
type KnowledgeDocument = {
  id: string; revision: number; tenantId: string;
  knowledgeBaseId: string | null; filename: string; contentType: string;
  chunkCount: number; status: 'ready'; contentExact: boolean;
  createdAt: number; updatedAt: number; content: string;
};
type KnowledgeMatch = {
  chunkId: string; documentId: string; knowledgeBaseId: string | null;
  filename: string; content: string; score: number; chunkIndex: number;
};

$AE.knowledge.list()

列出知识库及各知识库的文档数量。

$AE.knowledge.list(): Promise<{ bases: KnowledgeBase[] }>

权限：knowledge.read。参数：无。返回：知识库摘要，按最近更新时间排列；此方法不列出文档，也不返回正文。

const { bases } = await $AE.knowledge.list();

$AE.knowledge.search(args)

在知识内容中检索相关文本片段。

$AE.knowledge.search(args: {
  query: string; limit?: number; knowledgeBaseIds?: string[];
}): Promise<{ results: KnowledgeMatch[] }>

权限：knowledge.read。参数：query 为非空文本；limit 为正整数，默认 5。knowledgeBaseIds 每个为 1–4,096 字符，可填知识库 ID 或文档 ID；省略时搜索当前用户空间的全部知识文档，空数组返回空结果。

返回：匹配的文本片段，包含所属文档和知识库 ID。score 是检索得分，不是百分比或置信度；需要全文时用 documentId 调用 get()。

const { results } = await $AE.knowledge.search({ query: '验收标准', limit: 5 });

$AE.knowledge.get(args)

读取一份知识文档的正文和元数据。

$AE.knowledge.get(args: { id: string }): Promise<KnowledgeDocument | null>

权限：knowledge.read。参数：id 是文档 ID，而非知识库 ID，为 1–4,096 字符。返回：完整文档或 null；contentExact: false 表示旧文档正文由已有片段重建，不能视为原文的精确副本。

const document = await $AE.knowledge.get({ id: results[0].documentId });

$AE.knowledge.create(args)

创建一份可检索的纯文本知识文档。

$AE.knowledge.create(args: {
  filename: string; content: string; knowledgeBaseId?: string;
}): Promise<KnowledgeDocument>

权限：knowledge.write。参数：filename 为 1–4,096 字符，content 为非空文本。knowledgeBaseId 为 1–4,096 字符，指定已有知识库，省略时文档不归属某个知识库。

返回：新文档，contentType 为 'text/plain'，带文档 ID 和版本号。此方法创建文档，不创建知识库，也不按同名文件覆盖已有文档。

const document = await $AE.knowledge.create({ filename: 'review.md', content: report });

$AE.knowledge.update(args)

替换知识文档的全文并更新检索内容。

$AE.knowledge.update(args: {
  id: string; content: string; expectedRevision?: number;
}): Promise<KnowledgeDocument | null>

权限：knowledge.write。参数：id 是文档 ID，为 1–4,096 字符，content 为非空文本。expectedRevision 是可选正整数；传入先前读到的 revision 可避免覆盖并发修改。

返回：更新后的文档，版本号递增；未找到文档且未指定版本检查时返回 null。版本不匹配会报错。此方法不修改文件名或所属知识库。

await $AE.knowledge.update({ id: document.id, content: report, expectedRevision: document.revision });

MCP

必须绑定会话，使用当前工作区可用的已启用服务。SDK 不暴露服务连接凭据，也不安装或启用新服务。

$AE.mcp.list()

列出当前可用的 MCP 服务摘要。

$AE.mcp.list(): Promise<{ servers: Array<{ id: string; name: string; description: string }> }>

权限：mcp.read。参数：无。返回：服务 ID、名称和描述；不包含工具目录、参数 schema 或连接状态探测结果。

const { servers } = await $AE.mcp.list();

$AE.mcp.tools(args)

连接一个已启用服务，读取当前可用工具及其真实参数定义。

$AE.mcp.tools(args: { serverId: string }): Promise<{
  tools: Array<{ name: string; description?: string; inputSchema: Args }>;
}>

权限：mcp.read，必须绑定会话。参数：serverId 使用 mcp.list() 的 ID，为 1–4,096 字符。返回：已启用工具的名称、说明和 JSON Schema；不返回凭据，被禁用工具不会出现在列表中。服务连接失败会报错。

const { tools } = await $AE.mcp.tools({ serverId });

$AE.mcp.call(args)

调用一个已启用 MCP 服务中的工具。

$AE.mcp.call(args: { serverId: string; tool: string; arguments?: Args }): Promise<{ output: string }>

权限：mcp.invoke。参数：serverId 是服务 ID；tool 是该服务真实工具名，两者均为 1–4,096 字符。arguments 默认 {}，需符合该工具自身的接口。

返回：工具输出文本。未启用服务、被禁用工具或平台策略拒绝都会报错；SDK 不绕过这些限制。工具名称与参数从 mcp.tools() 或该服务公开说明取得。

const { output } = await $AE.mcp.call({ serverId, tool: toolName, arguments: toolArgs });

插件设置

设置按插件和当前用户空间隔离，不含平台模型密钥或全局安全配置。已安装插件的设置会持久保存；开发预览的设置仅属于当前开发会话。

$AE.settings.get()

读取当前插件自己的设置对象。

$AE.settings.get(): Promise<Args>

权限：settings.read。参数：无。返回：完整设置对象，未保存过时为 {}。

const settings = await $AE.settings.get();

$AE.settings.set(args)

整体保存当前插件的设置对象。

$AE.settings.set(args: { value: Args }): Promise<Args>

权限：settings.write。参数：value 必须是 JSON 对象。返回：保存后的完整对象。此次写入会替换旧对象；要保留其他字段，先读取再合并，另需 settings.read。

await $AE.settings.set({ value: { ...settings, modelId, rubric: '准确性与完整性' } });

$AE.call(capability, method, args?)

直接调用一个已公开的宿主能力方法，与对应的便捷方法使用同一权限和参数检查。

$AE.call(capability: string, method: string, args?: Args): Promise<unknown>

参数：capability 是能力 ID，method 是该能力的方法名，为 1–40 字符，args 默认 {}。例如 models.read + list 对应 models.list()，workspace.write + write 对应 workspace.write()。

权限与返回：与上文对应方法完全一致。此方法不能注册新能力、提升权限、访问未公开方法或更换绑定会话。常规开发优先使用便捷方法；call() 的返回类型需由调用方按目标接口处理。

const result = await $AE.call('models.read', 'list');
