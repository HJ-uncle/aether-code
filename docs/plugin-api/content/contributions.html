在 aether-plugin.json 的 contributes 中声明。以下位置均已开放；发布并启用插件后生效。开发模式可先预览页面和测试工具。

通用字段

字段 说明
id 必填，局部 ID；小写字母开头，允许数字和连字符，最多 48 字符；同类内唯一
title 必填，显示名称，1–120 字符
scope global（默认）或 session；后者需要绑定会话
when { session?, workspace?, engineReady? }，每项为布尔值，条件同时满足才显示
order −1000 至 1000 的整数；控制同类插件条目的排序

页面、工具、命令引用均填写本插件的局部 ID。scope: "global" 不代表可读取所有会话。

贡献和目标页面的显示条件都需满足。消息、会话、文件、编辑器、服务和输入框入口会绑定各自目标，工具通过 context() 读取；业务参数不能冒充另一个目标。贡献数组不附加固定数量上限，仍需避免过多入口干扰用户操作。

宿主会同步已发布且启用的插件，无需先进入插件管理页。停用、卸载、发布修订替换或切换引擎会清理对应挂载；短暂连接故障不会主动删除仍有效的界面注册。

pages

定义页面。页面定义本身不增加导航入口。

kind 必要字段 用途
tool id, title, kind；可选 tool 自动生成工具参数表单
webview id, title, kind, entry, tools 自包含 HTML 界面
native id, title, kind, entry；可选 tools，默认 [] JSON 原生组件 
{ "pages": [{ "id": "main", "title": "质量检查", "kind": "webview", "entry": "ui/main.html", "tools": ["review"] }] }

entry 为包内 .html 或 .json 路径；tools 为该页面可直接调用的工具白名单。使用平台 API 另需对应权限。

navigation

在左侧主导航添加页面入口。必要字段：id, title, page；可选 icon。

{ "navigation": [{ "id": "quality", "title": "质量检查", "page": "main", "icon": "puzzle" }] }

workspaceTabs

在右侧工作区添加可关闭页签，通过会话标题栏的「更多工作区」菜单打开。收起工作区会保留当前会话已打开的页签及顺序，仍可从该菜单选择插件页签并重新展开；点击页签的关闭按钮才会移除该页签。字段同 navigation。

工作区首页的「插件」分组也提供插件页签入口；关闭最后一个页签后返回工作区首页。

{ "workspaceTabs": [{ "id": "quality", "title": "质量检查", "page": "main", "scope": "session" }] }

commands

注册可从命令面板、菜单或快捷键执行的操作。必要字段：id, title，并在 tool、page 中二选一。可选 args, shortcut。

{
  "commands": [
    { "id": "review", "title": "检查当前目标", "tool": "review", "shortcut": "Mod+Shift+Y" },
    { "id": "open", "title": "打开检查页面", "page": "main" }
  ]
}

快捷键仅在应用窗口活动时生效；Mod 对应 macOS 的 Command、其他平台的 Control。保留菜单入口，避免快捷键冲突。

menus

将命令放到指定操作区域。必要字段：id, title, location, command。

{ "menus": [{ "id": "review-message", "title": "检查这条消息", "location": "message.actions", "command": "review", "scope": "session" }] }
location 位置 提供的目标上下文
message.actions 会话消息操作菜单，包括补充消息 消息 ID、角色、所属会话；只读转录不显示此菜单
session.context 左侧会话列表右键菜单 被点击的会话；当前不包含顶部会话菜单和项目页会话菜单
file.context 工作区文件树右键菜单 单个文件/目录路径；不传多选路径列表
editor.context 已接入的代码预览右键菜单 文件路径、打开菜单时的选择文本
editor.toolbar 该代码预览工具栏 文件路径、选择文本
app.menu 顶部应用菜单的插件操作 当前会话、工作区
service.context 底部活动、历史条目的右键菜单；工作区弹层中的服务条目不提供此菜单 当前显示区域的上下文；仍有实时实例的条目提供目标 ID
composer.toolbar 输入框工具栏 当前输入目标、会话

工具内通过 $AE.context() 读取目标。不同预览器拥有不同能力；editor.* 当前不覆盖成果文本、图片、PDF、Office 文档等所有预览。

service.context 也可出现在通知与持久历史摘要的菜单中。这些摘要不保证提供 targetId 或来源会话；不要把菜单的当前会话当作条目的来源会话。

views

把页面嵌入现有区域。必要字段：id, title, location, page；可选 height（40–1200，默认 280）。

{ "views": [{ "id": "review-card", "title": "消息检查", "location": "message.inline", "page": "main", "scope": "session", "height": 240 }] }
location 位置
message.inline 消息内部，可收起的扩展区域
composer.panel 输入框扩展区域
workspace.panel 工作区附加面板

默认收起，展开才加载；可同时展开多个，收起后释放页面。子代理转录也会复用消息内嵌区域，但当前没有专门的子代理运行 ID 上下文。

statusBar

在底部状态栏添加命令入口。必要字段：id, title, command；可选 icon。

{ "statusBar": [{ "id": "review", "title": "质量检查", "command": "open", "icon": "puzzle" }] }

settings

在全局设置中添加插件页面，支持按页面名称搜索。必要字段：id, title, page。

{ "settings": [{ "id": "preferences", "title": "质量检查设置", "page": "preferences" }] }

设置数据使用 $AE.settings 保存；当前不是自动生成设置字段的 Schema。

editorDecorations

在已接入的代码预览显示内容标记及提示。必要字段：id, title, text；可选 pattern, tooltip, severity。

{ "editorDecorations": [{ "id": "todo", "title": "待办", "pattern": "TODO", "text": "文件包含待办项", "severity": "info" }] }

pattern 为最长 200 字符的内容字面子串，不是文件 glob 或正则；每项最多标记 100 处。省略时只显示状态提示。severity 为 info、warning 或 error。

services

声明插件服务条目。必要字段：id, title, tool；可选 stopTool, statusTool, page, args。

会话作用域中运行或等待处理的服务显示在当前会话的「更多工作区」弹层与底部「活动」的进行中列表；没有内容的分组自动隐藏。工作区弹层内的「查看服务历史」始终可用，用于查看当前会话已完成、停止或失败的服务记录；重新打开弹层默认显示当前工作区与进行中内容。未运行的 idle 服务不显示在进行中列表或服务历史中，仍可通过 SDK 读取和启动。全局服务通过插件页面和 SDK 管理。底部「活动」同时显示未读通知，「历史」保留已读通知；服务状态变化不会自动产生通知，通知使用 $AE.ui.notify 发送。

工作区首页的「运行中」也按类别汇总当前会话的活跃服务；服务没有打开页面时仍计入摘要。

{ "services": [{ "id": "timer", "title": "计时器", "tool": "start_timer", "stopTool": "stop_timer", "statusTool": "timer_status", "page": "main", "scope": "session" }] }

页面通过 $AE.services 启动、停止和刷新。工具返回：

{ "result": { "status": "running", "detail": "等待完成", "completesAt": 1893456000000 } }

status 为 idle/running/waiting/completed/stopped/error；detail 为说明。可选 completesAt 是毫秒时间戳，实际使用时设置为未来 7 天内；到期后显示完成。服务状态不是持久调度，跨重启任务使用 background。

hooks

用事件触发工具。定义与示例见 事件 hooks。

background

声明可恢复的周期任务。定义与示例见 后台任务。

图标

navigation、workspaceTabs、statusBar 支持 puzzle、clock、clock-outline、activity、terminal、folder、file、bell、settings、globe、users。未识别名称显示默认拼图图标。

尚不能直接声明的区域

当前没有专用的对话多选、附件处理、工具结果渲染、子代理运行详情、项目详情、成果预览、浏览器网页工具栏、终端工具栏挂载声明。不要在 location 中填写自行命名的位置；未支持字段会被拒绝。
