插件是一个包含 aether-plugin.json 和所引用文件的目录。可在 Aether 的「插件 → 开发模式」中直接打开，修改后刷新即可运行。

也可以在会话中添加「插件管理」工具包，让 Agent 创建工程、修改源码、测试和发布。需要连续自动执行时，在操作确认卡中选择「完全访问并放行」，授权仅对当前会话生效；详见会话操作确认。

最小工程

text-counter/
├── aether-plugin.json
├── main.mjs
└── ui.html

aether-plugin.json：

{
  "apiVersion": 1,
  "id": "text-counter",
  "name": "字符统计",
  "version": "1.0.0",
  "description": "统计文本的 Unicode 字符数",
  "runtime": "node",
  "tools": [{
    "name": "count",
    "description": "统计文本字符数",
    "entry": "main.mjs",
    "inputSchema": {
      "type": "object",
      "properties": { "text": { "type": "string", "maxLength": 10000 } },
      "required": ["text"],
      "additionalProperties": false
    }
  }],
  "contributes": {
    "pages": [{ "id": "main", "title": "字符统计", "kind": "webview", "entry": "ui.html", "tools": ["count"] }],
    "navigation": [{ "id": "counter", "title": "字符统计", "page": "main", "icon": "puzzle" }]
  }
}

main.mjs：

try {
  let input = ''
  process.stdin.setEncoding('utf8')
  for await (const chunk of process.stdin) input += chunk
  const { tool, args } = JSON.parse(input)
  if (tool !== 'count' || typeof args.text !== 'string') throw new Error('参数无效')
  const result = { count: [...args.text].length }
  process.stdout.write(JSON.stringify({ result }) + '\n')
} catch (error) {
  console.error(error instanceof Error ? error.message : String(error))
  process.exitCode = 1
}

ui.html：

<main style="padding:16px">
  <label>文本 <textarea id="text">你好🍎</textarea></label>
  <button id="count" type="button">统计</button>
  <output id="result" aria-live="polite"></output>
</main>
<script>
  document.querySelector('#count').onclick = async () => {
    const output = document.querySelector('#result')
    try {
      const { result } = await $AE.invoke('count', {
        text: document.querySelector('#text').value
      })
      output.textContent = `${result.count} 个字符`
    } catch (error) {
      output.textContent = error.message
    }
  }
</script>

打开开发模式中的「界面预览」，点击统计，结果为 3 个字符。开发预览用于调试页面和工具；正式导航等挂载在发布、启用插件后出现。

清单字段

字段 必填 说明
apiVersion 是 当前为 1
id 是 1–48 位小写字母、数字、单连字符；首尾为字母或数字
name 是 显示名称，最多 120 字符
version 是 作者维护的版本字符串，最多 64 字符
description 是 功能说明，最多 2000 字符
runtime 是 当前为 "node"
tools 是 非空工具列表，见下表
contributes 否 页面、菜单等挂载声明
permissions.requested 否 所需权限，申请后仍需用户授权

tools[]：

字段 说明
name 本地工具名：小写字母开头，允许数字和下划线，最多 32 字符
description 工具说明，最多 4000 字符
entry 包内 .mjs 入口路径
inputSchema 参数 JSON Schema；推荐明确 properties、required 和 additionalProperties

页面调用填写本地工具名，如 count。不要自行添加 plugin_ 前缀。工具在平台中的全名总长最多 64 字符，插件 ID 较长时应缩短工具名。

version 由作者维护；平台的 revision 是保存草稿时生成的修订号，二者不同。发布固定修订及其内容哈希；继续编辑草稿不会立即替换已发布界面。

工具输入与输出

每次调用读取一份 stdin JSON：

{ "tool": "count", "args": { "text": "你好🍎" } }

向 stdout 输出一行 JSON：

{ "result": { "count": 3 }, "artifacts": [] }

日志写 stderr；失败使用非零退出码。每次调用独立运行，不用内存变量保存长期状态；持久配置使用 settings。

宿主写入请求后关闭 stdin，入口需读取到 EOF。stdout 的最后一个非空行作为 JSON 结果，也接受未包装的业务 JSON；只导出函数而不读取请求、输出结果不会被自动调用。非零退出码，或没有 result 的顶层 { error: "说明" } / { error: { message: "说明" } }，都视为失败。嵌套 result 的业务含义由插件负责验证。

文件产物格式：

{
  "result": { "message": "报告已生成" },
  "artifacts": [{ "path": "report.md", "content": "# 检查结果\n", "encoding": "utf8" }]
}

encoding 可为 utf8（默认）或 base64。产物数量和内容不设插件专属上限。工具测试和用户在插件页面中的调用只返回产物预览；主会话调用已选用插件的工具时，返回产物会按相对路径进入文件变更记录，可随会话回退，且不覆盖已有文件。插件代码主动写工作区用 workspace.write，让用户选择保存位置用 download。直接使用 Node 文件或网络接口产生的副作用不自动进入这条产物回退流程。

调试与分发

  1. 在「插件 → 开发模式」打开工程目录，按需要绑定会话、启用权限。
  2. 修改源码后点击刷新，在「界面预览」或「工具测试」验证结果。源码变化而未刷新时会拒绝运行旧快照。
  3. 通过插件管理导入目录或 ZIP，完成测试后发布、启用。也可在管理页导出工程供别人导入。

ZIP 根目录应直接包含 aether-plugin.json。GitHub 导入要求仓库采用平台支持的插件格式，并非任意仓库都可运行。

导入得到草稿；发布会启用当前修订。使用涉及平台能力的功能前，还需授权该修订申请的权限。已发布页面可从插件列表直接打开；要让主会话 Agent 调用插件工具，需在该会话中选用对应插件。安装、发布、启用、权限授权和会话选用分别生效，打开过插件页面不会自动把工具加入会话。

文件约束

文件使用 UTF-8，路径使用 / 分隔的包内相对路径。源码文件数、单文件、工程和页面大小不设插件专属上限。不包含凭据、缓存、数据库或 node_modules。Webview 的脚本和样式内联，第三方依赖需预先打包进自包含文件。

源码支持 .mjs .js .cjs .json .md .txt .svg .html .css .yaml .yml .csv 和 .d.ts；工具入口必须是 .mjs。路径最多 300 字符，不允许绝对路径、反斜杠、目录穿越、冒号、Windows 保留名称或仅大小写不同的重复文件；内容不得含 NUL。打包时不包含 .git、.staging、.versions 等内部目录。

inputSchema 支持常用类型、枚举、必填、范围和组合校验；不支持 $ref、正则 pattern、patternProperties、format、uniqueItems: true 或异步校验。复杂业务校验写在工具入口中。

Schema 根类型必须为 object，序列化后最多 64 KiB；JSON 结构最多 4096 个值、24 层深度，子 Schema 最多 256 个、16 层深度。单个组合最多 8 个分支，组合分支累计最多 32 个，单个 enum 最多 64 个值。校验不自动转换类型、填充默认值或删除额外参数。

Node 工具和工程测试默认不强加执行时限、V8 内存、输入输出字节配额。运行中的日志使用磁盘缓冲；返回的 stderr 是最多 64 KiB 的尾部预览，stderrTruncated: true 表示预览已省略更早日志，不影响完整结果。独立工程测试可主动设置 AETHER_PLUGIN_TEST_TIMEOUT_MS（正整数毫秒）限定运行时间，省略或 0 不附加时限。
