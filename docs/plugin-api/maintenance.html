维护 Aether 插件 API 参考

这是前端仓库内的独立静态 HTML 项目。公共内容唯一来源是 content/*.html，不再从 Markdown 构建。部署只需要 dist/；本说明、实现快照和检查脚本不会进入公开站点。

开发与构建

在前端仓库根目录安装已有依赖后运行：

npm run docs:dev       # http://127.0.0.1:4177；修改内容后刷新
npm run docs:build     # 生成 docs/plugin-api/dist/
npm run docs:check     # HTML、示例、SDK/挂载覆盖与实现快照
npm run docs:test      # 真实浏览器交互与离线/窄屏检查
npm run docs:package   # 打包可离线使用的纯 HTML 站点

也可以在本目录运行 npm run build、npm run dev、npm run check。依赖复用前端仓库的 Node 工具链，无单独的运行服务器或生产配置。构建后可直接打开 dist/index.html。

目录职责

  • pages.mjs：页面标题、分类、简介和输出文件名。
  • content/*.html：公开参考正文；标题使用稳定 id，保留既有深链接。
  • template.html、assets/：共用布局、主题、搜索与代码复制。
  • scripts/build.mjs：生成静态页面、页内目录、搜索索引和语法高亮。
  • scripts/check.mjs、contract.snapshot.json：实现与文档的交叉检查及经审阅指纹。
  • dist/：可部署成品；不要直接编辑。

功能变更必须同步

  1. 修改实现和对应 HTML。检查方法签名、入参、返回值、权限、适用位置、运行限制及完整例子。
  2. 运行 npm run docs:check。源码变化会被指出，尚未新增的接口也不能遗漏。
  3. 完成实际代码与文档交叉审阅，确认仅优化内部实现时公开契约仍未变化。
  4. 显式运行 npm run docs:review 记录确认；该命令不是自动生成文档，也不能替代审阅。
  5. 运行 npm run docs:check、npm run docs:test 和变更对应的业务测试。前端 npm run build 已包含同步检查。

检查默认使用同级 ai-agent-engine 仓库及其依赖，可用 AETHER_ENGINE_SOURCE_DIR 指定。缺少配对源码时检查失败，独立 HTML 构建仍可使用。检查不启动真实引擎，不读取用户数据库或密钥。

证据和限制

测试报告、截图、临时配置和隔离示例均放前端仓库 .e2e-tmp/plugin-api-site/。覆盖和指纹检查可发现遗漏与未审阅实现变动，不能证明所有业务语义正确；涉及真实模型、MCP、文件或权限行为的变更仍须跑相应测试。记录区分静态人工审阅、模拟、真实宿主和真实模型验证；没有运行的部分明确标记未验证。一次文档审阅不能作为此前业务测试通过的替代证据。
