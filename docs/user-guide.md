# Aether 使用指南

更新日期：2026-11-17。本文按当前源码中可达的默认界面整理，功能对应源码见[功能覆盖表](feature-map.md)。引擎版本、账号权限和服务端能力会影响部分按钮是否可用。

## 第一次使用

Aether 只有一个默认界面。左侧主导航包括工作台、项目、Agent、插件、自动化、引擎监控；会话工作区提供首页、成果、工作区、资料、浏览器、子代理、终端和 Git 等页签。旧协议或配置中的 `work`、`code` 不代表需要切换两套应用界面。

1. 打开「设置 → 引擎管理」，选择本地内置或远端服务，确认连接状态就绪。
2. 打开「设置 → 模型」，选择或添加服务商、模型 ID、接口地址和模型 API Key，并进行连接测试。
3. 在工作台新建任务，选择工作区，输入需求。可以附文件、粘贴图片或引用已有资源。
4. 运行中在会话查看进展、审批与提问；完成后从成果区查看交付和文件变化。

本地内置服务可在允许匿名使用的状态下先开始工作。个人账号用于在当前服务中识别和恢复身份；它与连接服务所需的实例令牌、调用模型所需的 API Key 是不同的凭据。账号并不自动提供模型额度，也不自动把本机文件同步到另一台电脑。

## 账号与连接

「个人账号」提供登录已有账号、创建新账号、导入恢复凭据和服务已配置的第三方登录入口。账号属于当前服务地址；切换服务后不能假定同一凭据仍对应同一份业务数据。

新账号创建后先保存恢复凭据，再按需设置资料。导出恢复文件或复制凭据不会更换密钥；重新生成密钥是独立操作。恢复文件只包含恢复身份所需的信息，不是会话、附件或工作区的备份。密钥更换、账号绑定等敏感操作可能要求在当前流程内重新验证。

已登录页面可管理资料、恢复凭据、已绑定的第三方账号和登录会话，区分当前设备会话与其他会话。登录过期应重新登录原账号；新建账号会建立另一份身份。退出前的凭据保存提示用于避免之后无法恢复账号。

远端连接在「引擎管理」填写服务地址、实例令牌和可选工作目录，再保存并重新连接。高级 API Key/JWT 属于服务认证，不能填入模型 API Key。个人账号登录优先于高级认证；退出或过期后不会自动重新启用旧高级凭据。详细流程和链路图见[账号与登录](accounts-and-login.md)。

## 模型、Agent 与工具资源

模型管理支持新增、编辑、删除、连接测试和能力检测。模型选择器与设置共用模型目录；能力检测结果由当前服务提供，不保证每个兼容接口都支持图片、工具或所有推理参数。

Agent 是一组指令、模型及资源选择。Agent 管理页可配置技能、MCP、知识库和允许工具。默认会话使用 `general` 工具配置；自动化编辑页仍可能用 Work / Code 文案选择工具配置，它不是应用界面模式。详见[工具配置与资源](tool-profiles.md)。

输入区可使用：

- `@` 引用文件、文件夹、代码片段、终端、Agent、网页、其他会话或工具包等可用条目。
- `/` 选择技能、MCP 与知识库资源。
- 附件入口添加文件和图片；选择可信的内置子代理条目委派任务。
- 模型、Agent、安全权限和会话记忆选项调整当前任务配置。

可见资源及可管理范围由服务端权限决定。绑定资源不等于将全部资源正文永久加入每次模型请求。

## 会话、补充与下一轮队列

输入区使用 Enter 发送，Shift+Enter 换行。运行中可以「立即补充」正在执行的需求，也可以「排到下一轮」。补充仍归属当前轮次，正文、引用和附件使用用户输入的展示方式，并可随过程折叠。

正在等待权限批准或问题答案时，应先处理对应卡片。即时补充受当前运行是否接受输入的能力限制；某些资源或工具配置变更需要下一轮才生效。

下一轮队列持久保存待执行条目，可编辑正文和引用、调整顺序、取消单条、清空待执行项或暂停后续发送。编辑条目保留已有附件；新文件从主输入区添加。上一轮成功结束后才自动推进；失败或发送结果不确定时会进入恢复状态，避免盲目重复提交。暂停队列不等于停止当前运行。

会话正文可收起过程、查看工具活动、使用消息导航、复制或导出选中的完整轮次。压缩后的展示历史可按入口加载完整对话；历史展示、模型上下文压缩和长期记忆是不同机制。

侧栏区分运行中、待授权、等你补充、同时待授权与补充、完成、失败、停止和中断；已完成但未查看的任务有未读提示。连接断开表示状态需要重新核实，不能直接推断任务已经停止。

会话菜单提供停止、重命名、置顶、颜色标记、添加到对话、复制、打开方式、导出、归档、恢复和删除等动作。项目与列表入口复用同一套会话动作。归档用于整理列表，不等于删除文件。

### 重新发送、删除和回退的区别

| 操作 | 会话历史 | 工作区文件 |
| --- | --- | --- |
| 添加到对话 | 保留历史，把原文、引用和附件加入草稿 | 不改变 |
| 重新发起／重新生成 | 删除选中轮次及之后的对话，再发送原输入 | 不自动回退 |
| 从此处重新编辑 | 删除选中轮次及之后的对话，把原输入放回草稿 | 不自动回退 |
| 用户消息菜单「回退文件」 | 对应文件安全回退成功后，才删除选中轮次及之后的历史 | 回退这些轮次的 AI 文件修改；冲突或缺失快照会报告并保留历史 |
| 删除本轮 | 只删除该轮用户与 AI 内容，后续轮次保留 | 不改变 |
| 成果区「撤回本轮成果」 | 保留对话 | 撤回该轮文件变化，包括已保留的变化 |
| 变更审阅「保留」 | 保留对话 | 保留当前文件，只清除待审阅标记 |

回退依赖记录的文件变化和快照，不是按成果卡片的显示文字删除目录。遇到文件被外部修改、快照缺失或版本冲突时，界面应展示未完成项；不能把部分成功当作全部回退。成果回退会刷新相关文件与预览状态。

## 工作区、项目与成果

新任务可以指定目录，也可以清除已选目录回到默认工作区。未指定统一默认目录时，每个任务使用独立目录。已经绑定或运行中的任务可能锁定目录选择，界面会说明原因；远端目录必须是引擎所在机器的绝对路径。

项目页按工作区聚合任务，并提供独立会话集合、搜索、置顶、归档和排序。项目可设置显示名、复制目录、在本机文件管理器打开本地目录。归档项目会保留任务和文件，运行中的任务也不会因此停止。

工作区文件树支持新建文件／文件夹、重命名、复制、剪切、粘贴、删除、复制路径、排序、定位与刷新。文件名过滤可搜索子目录；正文搜索使用单独的搜索入口。远端路径不会被当成本机同名路径打开，本机文件管理器入口对远端不可用。

资料页用于整理任务参考，移除资料不会删除历史消息中的附件。资源页签可打开成果、附件、工作区文件和网页；外部文件选择只授予所选文件的读取，不能据此读取任意目录。

成果区按当前任务／工作区范围组织交付文件与文件变化。打开成果依赖真实文件状态；文件已经不存在时不应把旧预览当作仍然有效的交付。单文件和批量回退都会进行安全检查，执行中、工作区未就绪或回退锁定时相关操作不可用。

远端服务通过绑定当前会话的文件接口支持上传、读取、文件树、搜索、变化审阅及相关工作区操作。具体能力仍取决于服务版本与权限；它不是把远端磁盘挂载到本机，不能用本地路径绕过远端授权。

## 子代理协作与复用

内置子代理角色包括调研、执行和通用。调研角色负责只读分析与证据；执行角色负责代码、文档及其他产物；通用角色处理混合任务。同一角色可以有多个任务实例。

子代理区可看运行状态、主代理发布的总结与子代理自己的历史内容。两者来源不同，主代理总结不代表子代理完整执行记录。可对运行中的子代理停止或补充需求，并给补充附引用和附件。

已完成的子代理支持继续工作；中断、失败或取消的任务可在能力允许时继续原任务。恢复沿用已有上下文，比另开一条无关联任务更适合接续工作。界面依赖服务端的持久化关系和续跑协议；重启电脑不会恢复原来的操作系统进程。服务能力缺失、父任务忙碌等状态会限制继续入口。

上下文压缩由引擎运行逻辑处理，前端展示引擎报告的状态。不要把子代理可续跑理解为永远保留无限长的模型上下文。

## 记忆、知识库、技能与 MCP

「设置 → 记忆」分别配置全局记忆和会话记忆的默认开关。输入区可为当前会话选择开启、关闭或跟随默认；服务端禁用会话记忆时不能从前端强制开启。

记忆页可以查看全局或指定会话的记录，按关键词和类型筛选，新增、编辑或删除。长期记忆是经过保存的事实、偏好、决策等记录，不是完整聊天记录；关闭记忆不能等同于删除会话历史或关闭上下文压缩。

知识库可管理库及文档，导入文件或文本，并执行检索测试。只有可读取来源正文的条目才有相应编辑能力。MCP 支持按项目或全局配置服务、连接参数、环境变量或请求头、工具禁用项与超时；可用传输方式由当前界面及服务决定。

技能设置可查看可用技能；只有服务端明确返回管理权限时，才提供创建、导入、启停、删除及导入历史等管理入口。技能也可由 Agent 或输入资源选择器使用，不应按旧「专家模式」判断是否可用。

## 自动化

自动化页可新建、编辑、搜索、暂停、恢复和删除规则，查看运行历史与持久收件箱。时间规则包括间隔，以及带时区的每日、工作日、每周等日历计划；其他表达式取决于服务能力。

目标可以是继续已有会话、每次创建新会话，或按授权来源会话的工作区创建新任务。已有会话继承固定的 Agent 与权限；工作区来源重新绑定会影响后续触发。编辑页可配置工具、思考、超时和通知策略。

暂停只阻止未来触发，不会停止已经在跑的任务。没有执行权限时，规则可能只能保存为暂停状态。计划由引擎执行；引擎真正退出时，不应期待它仍在后台执行。静默通知不会删除运行历史。

当前引擎在需要请求认证的部署中不支持自动派发。编辑器会显示这一限制，计划只能保存为已暂停，已有运行历史仍可查看；不是重新登录或点击恢复就能解除。是否可执行以引擎返回的 capabilities 为准，具体部署边界见[引擎调度说明](../../ai-agent-engine/docs/runtime-guide.md#调度队列与流程)。

## 浏览器

从工作区、菜单或命令入口打开浏览器，可使用多标签、地址导航、前进后退、刷新、缩放、桌面／移动／自定义视口，以及控制台和网络检查器。网络列表可以过滤并查看请求详情。

AI 操作网页需要连接引擎、选定会话并开启允许 AI 的设置；页面还必须归属当前会话。将当前网页添加到对话用于建立相关引用与归属。状态栏的「AI 可操作当前网页」反映当前实际条件。

本地 HTML／目录预览适用于本机选定的文件。远端项目应启动可访问的开发服务，再使用 URL；不能把远端路径传给本地文件预览。

普通网页与插件页是两种承载方式。插件页在隔离桥中运行，不支持普通原生网页的 AI 点击和截图。浏览器会话持久化控制网站登录／存储的保留，清理浏览数据会清除相应登录状态。详见[浏览器工作流](browser-workflow-reliability.md)。

## 文件与 Office 预览

默认工作区文件界面是只读预览，可以选择、复制、定位和引用代码。源码中的编辑器存储、保存命令和语言服务基础设施不等于默认界面已经提供完整可写 IDE。当前能力及缺口见[编辑器与预览边界](editor-code-oss.md)。

支持文本、Markdown、代码、图片、视频、PDF、Word、Excel、PowerPoint、CSV／TSV 等预览。图片可使用图像标注功能；PDF 和 Office 文档预览是只读的，不能据此编辑原文档或给 PDF 添加批注。

Word 分页、PowerPoint 布局与复杂 Excel 格式可能和原应用不同。Excel 公式显示文件中保存的缓存结果，不重新计算公式。预览对文件大小、页数、表格数据和解析时间设有限制，超限或不支持的文件应通过原应用打开。未知二进制可显示有限的十六进制内容。

## 搜索、Git、终端与服务

工作区正文搜索提供大小写、整词、正则及包含／排除条件。结果有数量上限并显示截断；替换应先审阅预览，无法完整读取的文件不能作为已安全替换的目标。搜索与替换都绑定发起时的会话和工作区身份。

Git 区提供仓库状态、差异、暂存／取消暂存、提交、分支、远端同步和冲突相关操作；具体按钮随仓库与服务状态变化。放弃 Git 改动与会话成果回退是两种机制。远端仓库使用对应引擎的工作区操作，不会回退到本地同名目录。

终端使用本地 PTY 或远端会话终端，可从工作区页签或 Ctrl + 反引号键打开。Agent 的后台命令是另一个执行通道，能查看状态、输出和退出码并停止；根对话结束不代表后台命令结束，重启引擎也不会自动重跑命令。

当前会话的服务入口在会话标题旁，可打开对应终端、停止和查看结束记录。底部状态栏的消息／消息历史负责全局插件通知，区分未读和已读；它们不是所有会话命令输出的统一日志。

## 设置、监控与插件

设置提供个人账号、引擎管理、外观、文本编辑器、终端、模型、文件、搜索、键盘、源代码管理、浏览器、安全、代码图、MCP、技能、知识库和记忆，可搜索设置并只看已修改项。外观支持浅色／深色及强调色；可通过键盘设置调整快捷方式。

常用入口为 Ctrl+Shift+P 命令面板、Ctrl+, 设置、Ctrl+Shift+M 模型。命令可用性取决于当前上下文；保存和语言操作需要可写编辑器，默认只读预览不提供该上下文。

引擎监控进入页面时读取一次诊断数据，之后由刷新图标手动更新。CPU、内存、进程 I/O、存储、连接健康、运行版本与数据目录等属于不同采样；实时会话状态更新不表示所有诊断数字也重新采样。存储卡片不是任意删除数据库的入口。

插件管理支持项目创建／导入、编辑、测试、发布、启停、授权及本地开发预览。已启用插件可贡献菜单、页面、工作区页签、设置、服务等入口。界面遵循授权与发布版本；普通网页不会因此获得插件权限。使用与开发细节以[插件 HTML 参考](plugin-api/content/overview.html)为准。

## 排查顺序与验证范围

连接异常时，先核对服务地址、实例状态和个人账号，再检查模型配置；账号过期与模型密钥失效是两类问题。操作落在错误目录时，核对当前会话的工作区绑定和本地／远端来源，不要只比较显示的路径文本。

文档描述的是当前源码行为和可达入口。本次文档核对不等于所有外部模型、第三方账号提供方、远端系统和 Office 文件都完成了实机兼容验证。具体测试结果应查看对应变更的验证记录，不沿用历史报告的通过数量。
