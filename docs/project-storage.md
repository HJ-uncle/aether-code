# 项目内的 Aether 数据目录

Aether 为用户项目生成的辅助文件统一使用项目根目录下的 `.ae/`。用户明确要求生成的源码、交付文档以及项目自身的构建输出，仍遵循项目约定。

| 用途 | 新路径 | 兼容处理 |
| --- | --- | --- |
| 上传、粘贴、终端选区附件 | `.ae/attachments/` | 历史消息中的旧附件路径仍可读取，不整体搬动项目的 `uploads/` |
| 项目技能与启停配置 | `.ae/skills/` | 读取 `.aether/skills/`、`SKILLs/`；同名技能优先使用新目录 |
| 项目 MCP 配置 | `.ae/mcp.json` | 首次修改承接旧配置；新文件建立后使用新文件，删除的条目不会从旧文件恢复 |
| 项目引擎配置 | `.ae/aether.json` | 兼容读取 `.aether/aether.json`，新配置优先 |
| 项目上下文 | `.ae/AE.md` | 兼容旧 `.aether/AE.md` 及根目录 `AE.md` |
| 代码图缓存 | `.ae/codegraph.db` | 重新索引生成新缓存，保留旧 `.codegraph/`；重建不删除其他 `.ae` 数据 |
| OpenSpec 规划工件 | `.ae/openspec/changes/` | 内置技能统一使用新路径，旧文档不删除 |
| 可视化讨论记录 | `.ae/brainstorm/` | 页面、状态、日志均在单次讨论子目录中 |
| Agent 临时工作文件 | `.ae/plans/`、`.ae/tmp/`、`.ae/logs/` | 默认行为约定；用户明确指定路径时遵从用户要求 |

全局账号、密钥、会话数据库、设置、共享技能仍属于应用用户数据目录，不复制进项目。显式配置的全局目录或 `MCP_CONFIG_PATH` 等路径覆盖保持有效。文件原子保存、TypeScript 诊断所需的短暂邻接文件保留在原位置，并在操作结束时清理。

不会自动移动项目原有的 `data/`、`docs/`、`uploads/` 或第三方工具目录，也不会删除遗留数据。旧技能的内容保留原处以维持已有引用；新建和导入写入 `.ae`，启停修改也使用新目录配置。

目录选择由客户端和配套引擎共同实现。更新后需重启应用；远端模式需要服务端同步更新引擎。代码图和远端语言服务默认跳过 `.ae` 内的辅助代码，资源管理器仍可查看该目录。
