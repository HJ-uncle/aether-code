# Aether 编辑器体验整合

日期：2026-09-30。保留 Aether 工作台，在现有 React / Monaco 编辑区内整合 Wuzu Code 源码编辑工作流。此前的 `editor-wuzu-code-comparison.md` 是实施前审计快照，本文件描述本次交付。

## 已接入的工作流

| 维度 | 功能与入口 |
|---|---|
| 对话上下文 | 选区右键或 `Ctrl+L` 添加到对话；工具栏、文件标签、资源管理器提供文件/目录入口，支持资源树多选。隐藏的对话面板会展开。引用保存准确选区及未保存全文快照，草稿恢复保留引用卡片和内容。 |
| 双栏编辑 | 工具栏“分栏”、标签右键或 `Ctrl+\` 打开右侧编辑组。两组独立标签、焦点、光标和滚动位置，共享同一文件的修改；分隔条支持拖动和键盘调整。 |
| 导航与设置 | 文件路径和符号面包屑、同级文件选择器、可筛选文件大纲；字体、字号、行高、连字、缩进、换行和小地图设置持久化。 |
| 源码预览 | Markdown / 静态 HTML 提供编辑、分屏预览、预览三种模式，预览使用未保存内容，加载工作区相对图片/CSS，源码与预览双向滚动。 |
| Git 差异 | 版本控制文件行打开 Monaco 双版本差异，支持并排/行内、前后跳转、刷新。工作区侧共享源码缓冲区并可显式保存，暂存区与原始版本只读。差异选区也可添加到对话。 |
| Git 源码操作 | 源码行边显示相对 HEAD 的实时更改，点击标记或 `F7` 查看更改块，支持逐块还原、撤销。冲突块支持当前/传入/双方三种解决动作。状态区显示对应提交作者与摘要。 |
| 项目语言服务 | 在现有 TS/JS 服务上补齐自动导入补全 resolve、快速修复、整理导入、文本重构、命令及反向工作区编辑；引用预览可读取尚未打开的目标文件。 |
| 文件同步与恢复 | 已打开文件监听外部/AI 改盘；无本地修改时刷新，有修改时保留缓冲区并提示冲突。按项目恢复打开标签、双栏归属、活动文件及未保存草稿。 |
| 内容保护 | 单关、批量关闭、快捷键和关闭编辑组走统一确认；保存失败或确认期间出现新输入时保留文档。截断的大文件只读。保存/恢复/重载使用文档身份与版本检查，防止迟到回包覆盖重开的文档。 |

## 实现边界

- 编辑组为左右两栏，不是任意网格；未新增标签拖排、固定和临时预览标签。
- 本次语言服务增强覆盖 TS/JS/TSX/JSX；没有新增 Vue 专用语言服务器或完整 VS Code 扩展宿主。
- HTML 是静态预览，不执行文件内脚本；网络资源、网站根路径资源和完整前端开发服务器预览不在本次范围。
- 重构支持文本编辑；服务器创建、移动和删除文件的资源操作会明确拒绝，避免只执行半个重构。
- 草稿备份使用本地存储并防抖写入；存储不足会提示。不是具备事务日志的零损失崩溃恢复。尚未新增编码选择和多编码保真保存。
- 保存前的磁盘比对用于发现已知外部冲突，不等于操作系统级原子比较交换。

## 验证

`npm run build` 通过，其中包含 Node 和 Web 两段 `typecheck`。编辑器、语言服务、对话引用、文件恢复、Git 及基础工作台定向回归为 **148 passed / 0 failed**，包含真实 Electron 窗口交互以及纯逻辑竞态和协议验证。

随后以单 worker 串行执行全量 E2E：**393 passed / 1 failed / 2 did not run**。唯一失败是模型设置测试使用了全页面“编辑”按钮选择器，与菜单栏同名按钮冲突；已将选择器限定到设置视图，复跑该组得到 **3 passed / 0 failed**。两次合计覆盖全部 **396 条用例且均已通过验证**，不是单次全量运行的结果。

收尾复跑在当前沙箱内遇到 Electron GPU 子进程启动崩溃；在沙箱外使用原始启动参数运行上述 3 条用例通过，未为通过测试改动产品的 GPU 配置。
