# Agent 工具衔接问题调查与修复

## 证据与结论

依据用户粘贴的五子棋 H5 开发报告和对应会话的原始工具调用记录，区分工具接口缺陷、执行环境限制和模型生成代码的错误。未修改原会话、历史文件或用户生成的游戏。

| 现象 | 原始调用所证明的原因 | 修复 |
| --- | --- | --- |
| 连续几次命令无法启动 | 把 `node -v`、`where python` 和整行 `cmd /c ...` 放进 `command`，引擎按程序名 spawn，返回 ENOENT | command/args 增加明确示例；整行误用返回纠正方法；保持显式程序/argv 与既有权限检查 |
| 写完文件马上编辑却版本冲突 | 两次 write→edit 使用了不匹配版本；write 未向模型返回实际落盘版本 | write 的正文和 metadata 返回 canonical path、expectedHash；edit 可复用最近 read/write/edit 返回的版本，仍拒绝过期版本 |
| 复制报告只有“命令失败” | 普通工具的 result 未被写入复制文本，实际 stderr 丢失 | 复制保留命令、参数、工作目录、退出码、实际错误输出；过长输出保留首尾并标注省略 |
| 不清楚环境和可用能力 | get_current_context 只有工作区、工具摘要等，没有程序参数用法和运行平台 | 返回引擎平台/运行时与实际注册能力；不把引擎 Node 版本当作 PATH 程序保证，不把注册浏览器工具当作已连接 |
| HTML 诊断失败 | 当时只有 TypeScript/ESLint 适配器，HTML 不受支持 | schema 和失败结果明确后缀、配置要求及替代验证；unsupported 明确为未验证 |

额外在本机复现 Windows 裸 `npm` 查找、`.cmd` 启动和参数转义问题，一并修复批处理程序启动。原生日志不能证明当次五子棋任务调用过 npm；这是修复期间复现的同类集成问题。

## 不能归为工具故障的部分

- 正确拆分 command/args 后，Node 能运行。Python 当时不可用是环境事实。
- 后续多数非零退出来自生成的测试：语法错误、ESM 中使用 require、错误断言和坐标/数组索引约定混淆。执行器确实执行了脚本，原始 stderr 也已传给模型。
- 模型先误判产品实现，再发现测试坐标错误，这是推理问题。执行协议补充先检查测试夹具与预期值的要求，但不能保证模型从此不误判。
- 原任务注册表没有 browser 工具，其当时“无法直接做浏览器验证”的说法有记录支持。当前开发中的浏览器能力不能反推旧会话已有该能力。
- 原任务最后记录了 28 条测试通过和 11 条结构检查通过。这是历史证据，不是本次修复重新运行游戏的结果。

## 验证

本次使用本地确定性模型夹具验证工具协议，不调用付费模型。真实 Electron 与真实引擎用于检查消息往返、磁盘副作用和复制报告；单元测试覆盖版本冲突、参数误用和 Windows 启动边界。

- 客户端 `npm run typecheck`、`npm run build` 通过。
- 引擎 `npm run typecheck`、`npm run build` 通过；最终用于真实窗口测试的构建指纹为 `sha256:1e395bccb4ace3d673d6f0364808c05035c6ae40b08b5cc58d0ce26d39b1f9e8`。
- 引擎：文件编辑/变更记录/诊断 54 条、上下文/执行协议 9 条、安全策略 10 条、命令启动/工具/生命周期 50 条，共 **123 passed**，含本机 Windows 真实进程。
- 客户端：`tool-feedback`、`command-job-contract`、`command-job-store` 共 **20 passed**。
- 真实 Electron：`tool-ergonomics-ui`、`command-job-ui` 共 **7 passed**，覆盖实际落盘、write 返回版本直接 edit、带引号 Node 源码、模型收到非零退出与 stderr、HTML unsupported、真实复制/刷新回放、后台任务取消/超时/引擎重启恢复。
- 新真实窗口用例首轮失败是测试没有处理已有策略要求的命令确认卡。补上确认卡交互后通过，未为测试放宽命令策略。

这证明接口链路及列出的回归场景通过，不代表再次用原模型完成整场五子棋任务，也不代表所有模型均能正确推理测试坐标。

## 生效范围

修改涉及本仓库客户端和同级 `ai-agent-engine`。开发运行需重新构建并重启两端；若设置选择的是导入的旧引擎包，应更新该包后重启，仅刷新界面不会替换旧引擎。不会自动改写既有历史报告。
